Simplify \(\dfrac{(2x^3)^4 \times 8x^{-5}}{4x^2}\).

  1. A\(32x^{9}\)
  2. B\(16x^{7}\)
  3. C\(x^{5}\)
  4. D\(16x^{5}\)
  5. E\(4x^{5}\)
  6. F\(32x^{5}\)
Worked solution

\((2x^3)^4 = 16x^{12}\), so the numerator is \(16x^{12}\times 8x^{-5} = 128x^{7}\). Dividing by \(4x^2\) gives \(32x^{5}\).

Find the value of \(\left(\dfrac{27}{8}\right)^{-\frac{2}{3}}\).

  1. A\(\dfrac{9}{4}\)
  2. B\(-\dfrac{4}{9}\)
  3. C\(\dfrac{4}{9}\)
  4. D\(-\dfrac{9}{4}\)
  5. E\(\dfrac{2}{3}\)
  6. F\(\dfrac{3}{2}\)
Worked solution

The negative index inverts the fraction: \(\left(\frac{8}{27}\right)^{2/3}\). Cube root first: \(\left(\frac{2}{3}\right)^2 = \frac{4}{9}\).

Solve \(4^{x+1} = 8^{2x-3}\).

  1. A\(x = \dfrac{11}{4}\)
  2. B\(x = \dfrac{5}{4}\)
  3. C\(x = \dfrac{9}{4}\)

Worked solution

Write both sides as powers of 2: \(2^{2x+2} = 2^{6x-9}\). So \(2x + 2 = 6x - 9\), giving \(4x = 11\) and \(x = \frac{11}{4}\).

  1. A\(15 - 10\sqrt{5}\)
  2. B\(\dfrac{-15 + 10\sqrt{5}}{11}\)

Solve \(9^{x} - 4\times 3^{x} + 3 = 0\).

  1. A\(x = 1\) only
  2. B\(x = 0\) or \(x = 1\)
  3. C\(x = -1\) or \(x = 0\)
  4. D\(x = 0\) only
  5. E\(x = \log_3 4\)
  6. F\(x = 1\) or \(x = 3\)
Worked solution

Let \(y = 3^x\): \(y^2 - 4y + 3 = (y-1)(y-3) = 0\), so \(3^x = 1\) or \(3^x = 3\), giving \(x = 0\) or \(x = 1\).

How many real solutions does the equation \(2^{x^2} = 16 \times 2^{-3x}\) have?

  1. A\(3\)
  2. B\(2\)
  3. C\(4\)
  4. D\(1\)
  5. E\(0\)
  6. Finfinitely many
Worked solution

Given that \(\sqrt{a} - \sqrt{b} = 2\) and \(a - b = 12\), find \(\sqrt{a} + \sqrt{b}\).

  1. A\(4\)
  2. B\(8\)
  3. C\(10\)
  4. D\(6\)
  5. E\(24\)
  6. F\(3\)
Worked solution

If \(x = 2^{p}\), \(y = 2^{q}\) and \(\dfrac{x^{3}}{y^{2}} = 2^{5}\) with \(xy = 2^{10}\), find \(p\).

  1. A\(3\)
  2. B\(7\)
  3. C\(8\)
  4. D\(4\)
  5. E\(6\)
  6. F\(5\)
Worked solution

\(3p - 2q = 5\) and \(p + q = 10\). From the second, \(q = 10 - p\); then \(3p - 20 + 2p = 5\), so \(5p = 25\) and \(p = 5\).

Given that \((2 + \sqrt{3})^2 = a + b\sqrt{3}\) and \((2+\sqrt{3})^{-1} = c + d\sqrt{3}\), where \(a\), \(b\), \(c\), \(d\) are integers, find the value of \(a + b + c + d\).

  1. A\(14\)
  2. B\(4\)
  3. C\(6\)
  4. D\(10\)
  5. E\(12\)
  6. F\(8\)
Worked solution

\((2+\sqrt3)^2 = 7 + 4\sqrt3\), so \(a = 7\), \(b = 4\). \((2+\sqrt3)^{-1} = \dfrac{2-\sqrt3}{4-3} = 2 - \sqrt3\), so \(c = 2\), \(d = -1\). Sum \(= 7 + 4 + 2 - 1 = 12\).

19Indices and surds · spec MM1.2 · Paper 2 style · ★★☆

Which of the following statements is/are true for all positive real numbers \(a\) and \(b\)?

  1. I\(\sqrt{a} \sqrt{b} = \sqrt{ab}\)
  2. II\(\sqrt{a + b} = \sqrt{a} + \sqrt{b}\)
  3. III\(\sqrt{a^2 + b^2} < a + b\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I is a law of surds. II fails for \(a = b = 1\): \(\sqrt2 \neq 2\). III: \((a+b)^2 = a^2 + b^2 + 2ab > a^2 + b^2\) since \(ab > 0\), and both sides are positive, so III is true.

Which one of the following is the largest?

  1. A\(2\sqrt{4.5}\)
  2. B\(\sqrt{2} + \sqrt{7}\)
  3. C\(\sqrt{3} + \sqrt{6}\)
  4. D\(\sqrt{4} + \sqrt{5}\)
  5. E\(\sqrt{1} + \sqrt{8}\)
Worked solution

Each option is \(\sqrt a + \sqrt b\) with \(a + b = 9\). Squaring gives \(9 + 2\sqrt{ab}\), which is largest when the product \(ab\) is largest, i.e. when \(a\) and \(b\) are as close as possible. Option E has \(a = b = 4.5\) (product \(20.25\)), beating \(4 \times 5 = 20\) for option C. Numerically: E \(= \sqrt{18} \approx 4.243\), C \(= 2 + \sqrt5 \approx 4.236\).

22Indices and surds · spec MM1.1 · Paper 2 style · ★★☆

\(a\) and \(b\) are positive real numbers. Which of the following statements is/are true?

  1. IIf \(a^2 = b^2\) then \(a = b\).
  2. IIIf \(2^a = 2^b\) then \(a = b\).
  3. IIIIf \(a^b = 1\) then \(a = 1\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I holds because \(a, b > 0\) rules out \(a = -b\). II holds because \(2^x\) is one-to-one. III: for positive \(a\) and \(b\), \(a^b = 1\) gives \(b\log a = 0\), so \(\log a = 0\) and \(a = 1\). All three are true.

23Indices and surds · spec MM1.1 · Paper 2 style · ★★★

For how many integer values of \(n\) with \(1 \leq n \leq 100\) is \(\sqrt{n} + \sqrt{n+1}\) rational?

  1. A\(9\)
  2. B\(1\)
  3. C\(10\)
  4. D\(0\)
  5. E\(2\)
  6. F\(100\)
Worked solution

For the sum to be rational, both \(\sqrt n\) and \(\sqrt{n+1}\) would need to be rational (if one is irrational, \(\sqrt n + \sqrt{n+1}\) squared gives \(2n + 1 + 2\sqrt{n(n+1)}\) and \(n(n+1)\) is never a perfect square for \(n \geq 1\) since \(n^2 < n(n+1) < (n+1)^2\)). No two consecutive positive integers are both squares, so the answer is \(0\).
