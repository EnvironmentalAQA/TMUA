1Quadratic functions · spec MM1.3 · Paper 1 style · ★☆☆

The graph of \(y = x^2 + bx + c\) crosses the \(x\)-axis at \((1, 0)\) and \((5, 0)\). What is the \(y\)-coordinate of the vertex?

  1. A\(-9\)
  2. B\(5\)
  3. C\(-4\)
  4. D\(-3\)
  5. E\(4\)
  6. F\(-5\)
Worked solution

\(y = (x-1)(x-5)\), vertex at \(x = 3\): \(y = (2)(-2) = -4\).

2Integration · spec MM7.2 · Paper 1 style · ★☆☆

Find \(\displaystyle\int \left(x + \dfrac{1}{x}\right)^2 dx\).

  1. A\(\dfrac{x^3}{3} + 2x - \dfrac{1}{x} + c\)
  2. B\(\dfrac{x^3}{3} - \dfrac{1}{x} + c\)
  3. C\(\dfrac{1}{3}\left(x + \dfrac1x\right)^3 + c\)
  4. D\(\dfrac{x^3}{3} + 2x + \dfrac{1}{x} + c\)
  5. E\(\dfrac{x^3}{3} + 2x + c\)
  6. F\(x^3 + 2x - \dfrac1x + c\)
Worked solution

\(\left(x + \frac1x\right)^2 = x^2 + 2 + x^{-2}\), which integrates to \(\frac{x^3}{3} + 2x - x^{-1} + c\). (Option E is a common error: you cannot integrate a power of a bracket that way.)

3Indices and surds · spec MM1.1 · Paper 1 style · ★☆☆

Solve \(4^{x+1} = 8^{2x-3}\).

  1. A\(x = \dfrac{11}{4}\)
  2. B\(x = \dfrac{5}{4}\)
  3. C\(x = \dfrac{9}{4}\)
  4. D\(x = \dfrac{7}{2}\)
  5. E\(x = 2\)
  6. F\(x = 4\)
Worked solution

Write both sides as powers of 2: \(2^{2x+2} = 2^{6x-9}\). So \(2x + 2 = 6x - 9\), giving \(4x = 11\) and \(x = \frac{11}{4}\).

4Identifying errors in proofs · spec Err2 · Paper 1 style · ★☆☆

A student argues: 'Every prime number is odd, because if it were even it would be divisible by \(2\) and so not prime.' Which of the following is correct?

  1. AThe argument is wrong because \(2\) is even and prime: being divisible by \(2\) does not stop \(2\) itself being prime.
  2. BThe argument is correct.
  3. CThe argument is wrong because some odd numbers are not prime.
  4. DThe argument is wrong because \(1\) is odd and not prime.
  5. EThe argument is wrong because \(0\) is even.
Worked solution

A number divisible by \(2\) is not prime unless it equals \(2\). The conclusion 'every prime is odd' is false.

5Mathematical proof · spec Prf1 · Paper 1 style · ★☆☆

Consider the claim: **for every positive integer \(n\), \(n^2 + n\) is even.** Which of the following is a complete and valid proof?

  1. A\(n^2 + n\) is even because both \(n^2\) and \(n\) are even.
  2. BIf \(n\) is even then \(n^2\) is even and so \(n^2 + n\) is even.
  3. CSuppose \(n^2 + n\) is odd. Then \(n\) is odd, so \(n^2\) is odd, so \(n^2 + n\) is even, which is a contradiction... unless \(n\) is even.
  4. D\(1^2 + 1 = 2\), \(2^2 + 2 = 6\), \(3^2 + 3 = 12\), which are all even, so the claim holds.
  5. E\(n^2 + n = n(n + 1)\) is the product of two consecutive integers, one of which must be even, so the product is even.
Worked solution

A covers every \(n\) with a general argument. B checks only three cases; C handles only even \(n\); D is false for odd \(n\); E is incomplete.

Answer E · Mathematical proof (Prf1) · question PRF-01
6Identifying errors in proofs · spec Err2 · Paper 1 style · ★☆☆

Here is a purported proof that \(1 = 2\).

  1. ILet \(a = b\), with \(a \neq 0\).
  2. IIThen \(a^2 = ab\).
  3. IIISo \(a^2 - b^2 = ab - b^2\), i.e. \((a - b)(a + b) = b(a - b)\).
  4. IVDividing both sides by \((a - b)\): \(a + b = b\).
  5. VSo \(2b = b\), and hence \(2 = 1\).

On which line does the first error occur?

  1. AIV
  2. BII
  3. CIII
  4. DV
  5. EI
Worked solution

Since \(a = b\), \(a - b = 0\) and dividing by zero is invalid.

9Mathematical proof · spec Prf4 · Paper 1 style · ★☆☆

A proof that **if \(a\) and \(b\) are positive real numbers then \(\dfrac{a + b}{2} \geq \sqrt{ab}\)** is given with its lines scrambled.

  1. IHence \(a + b \geq 2\sqrt{ab}\), and dividing by \(2\) gives the result.
  2. IIExpanding, \(a - 2\sqrt{ab} + b \geq 0\).
  3. IIISince squares are non-negative, \((\sqrt a - \sqrt b)^2 \geq 0\).

Which order gives a valid proof?

  1. AIII, II, I
  2. BI, II, III
  3. CII, III, I
  4. DIII, I, II
  5. EII, I, III
Worked solution

Start from a known truth (III), expand (II), rearrange (I). Starting from the result and working backwards (I, II, III) would need every step to be reversible and is presented in the wrong direction.

10Mathematical proof · spec Prf1 · Paper 1 style · ★☆☆

Here is a proof that \(\sqrt{2}\) is irrational, with its steps in the wrong order.

  1. IThen \(p^2 = 2q^2\), so \(p^2\) is even, so \(p\) is even; write \(p = 2k\).
  2. IISuppose, for contradiction, that \(\sqrt2 = \dfrac{p}{q}\) where \(p\) and \(q\) are positive integers with no common factor.
  3. IIIThis contradicts the assumption that \(p\) and \(q\) have no common factor, so \(\sqrt2\) is irrational.
  4. IVThen \(4k^2 = 2q^2\), so \(q^2 = 2k^2\) is even, so \(q\) is even.

Which is the correct order?

  1. AII, I, IV, III
  2. BI, II, IV, III
  3. CII, IV, I, III
  4. DI, IV, II, III
  5. EII, I, III, IV
Worked solution

Assume (II), deduce \(p\) even (I), deduce \(q\) even (IV), reach the contradiction (III).

11Pythagoras, mensuration and 3D · spec M5.16 · Paper 2 style · ★☆☆

\(P\): 'a solid cylinder and a solid cube have equal volumes'. \(Q\): 'the cylinder and the cube have equal surface areas'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

Equal volumes say nothing about surface areas (a long thin cylinder has a large surface area), and equal surface areas say nothing about volumes. Neither implies the other.

12Sequences and series · spec MM2.2 · Paper 2 style · ★☆☆

An arithmetic sequence has first term \(a\) and common difference \(d\), both non-zero. Which of the following statements is/are true?

  1. IIf \(d > 0\) then every term after some point is positive.
  2. IIThe sum of the first \(n\) terms is a quadratic function of \(n\).
  3. IIIIf \(a\) and \(d\) are integers then \(S_n\) is an integer for every \(n\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: terms \(a + (n-1)d\) eventually exceed any bound. II: \(S_n = \frac n2(2a + (n-1)d)\) is quadratic in \(n\). III: \(S_n\) is a sum of integers.

13Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

A bag contains red and blue balls only. If one red ball is removed, one quarter of the remaining balls are red. If instead two blue balls are removed, one third of the remaining balls are red. How many balls are in the bag?

  1. A\(16\)
  2. B\(20\)
  3. C\(14\)
  4. D\(8\)
  5. E\(17\)
  6. F\(12\)
Worked solution

With \(r\) red and \(b\) blue: \(r - 1 = \frac14(r + b - 1)\) and \(r = \frac13(r + b - 2)\). The second gives \(b = 2r + 2\); substituting into the first, \(4r - 4 = 3r + 1\), so \(r = 5\), \(b = 12\): \(17\) balls.

Answer E · Chains of reasoning (Prf5) · question RSN-19
14Number, units and estimation · spec M2.3 · Paper 2 style · ★★☆

\(n\) is a positive integer such that \(n\), \(n + 2\) and \(n + 4\) are all prime. Which of the following statements is/are true?

  1. IThere is exactly one such value of \(n\).
  2. II\(n\) must be odd.
  3. IIIOne of \(n\), \(n + 2\), \(n + 4\) must be divisible by \(3\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Among any three numbers of the form \(n, n+2, n+4\) one is a multiple of \(3\) (they cover all residues mod \(3\)) - III. So one of them must equal \(3\) itself for all to be prime, giving \(n = 3\) only (\(3, 5, 7\)) - I. And \(3\) is odd - II.

Answer H · Number, units and estimation (M2.3) · question NUM-12
15Exponentials and logarithms · spec MM5.3 · Paper 2 style · ★★☆

Consider the statement: **for all real \(x\), \(2^{x} > x^2\).** Which of the following is a counterexample?

  1. A\(x = 5\)
  2. B\(x = 3\)
  3. C\(x = 0\)
  4. D\(x = 10\)
  5. E\(x = 1\)
Worked solution

16Identifying errors in proofs · spec Err1 · Paper 1 style · ★★☆

Claim: the sum of the first \(n\) odd numbers is \(n^2\).

  1. IThe first odd number is \(1 = 1^2\), so the claim holds for \(n = 1\).
  2. IISuppose the claim holds for some \(n\), i.e. \(1 + 3 + \cdots + (2n - 1) = n^2\).
  3. IIIAdding the next odd number, \(2n + 1\), gives \(n^2 + 2n + 1 = (n + 1)^2\).
  4. IVSo the claim holds for \(n + 1\), and hence for all positive integers \(n\).

Which of the following is correct?

  1. AThe proof is completely correct.
  2. BThe first error is on line II: you cannot assume the claim.
  3. CThe first error is on line III: the next odd number is \(2n - 1\).
  4. DThe first error is on line IV: it only shows the claim for \(n + 1\).
  5. EThe first error is on line I.
Worked solution

This is a valid proof by induction: a base case, and a step showing that truth for \(n\) implies truth for \(n + 1\).

Answer A · Identifying errors in proofs (Err1) · question ERR-15
17Number, units and estimation · spec M2.3 · Paper 2 style · ★★☆

\(n\) is a positive integer greater than \(1\). Which of the following statements is/are true?

  1. IIf \(n\) is not prime, then \(n\) has a prime factor at most \(\sqrt n\).
  2. IIIf \(n\) has no prime factor at most \(\sqrt n\), then \(n\) is prime.
  3. IIIIf \(n\) is prime, then \(n\) has no factor between \(1\) and \(n\) exclusive.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

If \(n = ab\) with \(1 < a \leq b\) then \(a \leq \sqrt n\) and \(a\) has a prime factor \(\leq \sqrt n\) (I). II is the contrapositive of I. III is the definition of prime.

Answer H · Number, units and estimation (M2.3) · question X2-18
18Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

Five friends each shake hands with some of the others (each pair shakes hands at most once). Which of the following is impossible?

  1. AEvery friend shakes hands with exactly two others.
  2. BEvery friend shakes hands with exactly four others.
  3. CThe numbers of handshakes made are \(1, 1, 2, 2, 2\).
  4. DThe numbers of handshakes made by the five friends are \(4, 4, 4, 4, 1\).
  5. EExactly one friend shakes no hands at all.
Worked solution

If four people each shook hands with all four others, everyone shook hands with everyone, so the fifth person also made \(4\) handshakes, not \(1\). The others can happen: B is a pentagon of handshakes, C is everyone with everyone, D is a chain, E leaves one person out.

Answer D · Chains of reasoning (Prf5) · question RSN-03
19Quadratic functions · spec MM1.3 · Paper 2 style · ★★☆

The function \(f(x) = x^2 - 6x + 13\) is defined for all real \(x\). Which of the following statements is/are true?

  1. I\(f(x) > 0\) for all real \(x\)
  2. IIThe graph of \(y = f(x)\) is symmetric about the line \(x = 3\)
  3. IIIThe equation \(f(x) = 4\) has exactly one real solution
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(f(x) = (x-3)^2 + 4 \geq 4 > 0\), so I is true. The axis of symmetry is \(x = 3\), so II is true. \(f(x) = 4\) only when \((x-3)^2 = 0\), i.e. \(x = 3\): exactly one solution, so III is true.

Answer H · Quadratic functions (MM1.3) · question QUA-06
20Binomial expansion · spec MM2.4 · Paper 2 style · ★★☆

\(n\) is a positive integer. Which of the following statements is/are true?

  1. IThe coefficient of \(x^n\) in \((1 + x)^{2n}\) is \(\binom{2n}{n}\).
  2. IIThe sum of the coefficients in the expansion of \((1 - x)^n\) is \(0\).
  3. III\((1 + x)^n \geq 1 + nx\) for all \(x \geq 0\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I is the general term with \(r = n\). II: put \(x = 1\). III: expanding \((1 + x)^n\) gives \(1 + nx\) plus non-negative terms when \(x \geq 0\).
