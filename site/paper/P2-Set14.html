1Quadratic functions · spec MM1.3 · Paper 1 style · ★☆☆

By completing the square, find the minimum value of \(2x^2 - 12x + 23\).

  1. A\(-13\)
  2. B\(5\)
  3. C\(23\)
  4. D\(7\)
  5. E\(-5\)
  6. F\(3\)
Worked solution

\(2x^2 - 12x + 23 = 2(x-3)^2 - 18 + 23 = 2(x-3)^2 + 5\), so the minimum is \(5\) (at \(x = 3\)).

2Straight lines · spec MM3.1 · Paper 1 style · ★☆☆

The perpendicular bisector of the line segment joining \((1, 5)\) and \((7, 1)\) has equation

  1. A\(3x - 2y = 6\)
  2. B\(2x - 3y = -1\)
  3. C\(3x + 2y = 18\)
  4. D\(2x + 3y = 17\)
  5. E\(y = \frac32 x - 3\)
  6. F\(3x - 2y = 18\)
Worked solution

Midpoint \((4, 3)\); gradient of segment \(\frac{-4}{6} = -\frac23\), so the bisector has gradient \(\frac32\): \(y - 3 = \frac32(x - 4) \Rightarrow 2y - 6 = 3x - 12 \Rightarrow 3x - 2y = 6\).

3Indices and surds · spec MM1.1 · Paper 1 style · ★☆☆

Find the value of \(\left(\dfrac{27}{8}\right)^{-\frac{2}{3}}\).

  1. A\(\dfrac{9}{4}\)
  2. B\(-\dfrac{4}{9}\)
  3. C\(\dfrac{4}{9}\)
  4. D\(-\dfrac{9}{4}\)
  5. E\(\dfrac{2}{3}\)
  6. F\(\dfrac{3}{2}\)
Worked solution

The negative index inverts the fraction: \(\left(\frac{8}{27}\right)^{2/3}\). Cube root first: \(\left(\frac{2}{3}\right)^2 = \frac{4}{9}\).

4Probability · spec M7.7 · Paper 2 style · ★☆☆

\(P(A) = 0.6\), \(P(B) = 0.5\) and \(P(A \text{ and } B) = 0.3\). Which of the following statements is/are true?

  1. I\(A\) and \(B\) are independent.
  2. II\(A\) and \(B\) are mutually exclusive.
  3. III\(P(A \text{ or } B) = 0.8\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(P(A)P(B) = 0.3 = P(A \text{ and } B)\), so independent (I). Not mutually exclusive since they can both happen (II false). \(P(A \text{ or } B) = 0.6 + 0.5 - 0.3 = 0.8\) (III).

5Identifying errors in proofs · spec Err2 · Paper 1 style · ★☆☆

Claim: if \(x\) and \(y\) are real with \(x^2 = y^2\), then \(x = y\).

Which of the following is a counterexample to the claim?

  1. A\(x = -1\), \(y = -1\)
  2. B\(x = 1\), \(y = 2\)
  3. C\(x = 2\), \(y = -2\)
  4. D\(x = 0\), \(y = 0\)
  5. E\(x = 2\), \(y = 2\)
Worked solution

A counterexample must satisfy the hypothesis (\(x^2 = y^2\)) and fail the conclusion (\(x \neq y\)).

6The logic of arguments · spec Arg1 · Paper 1 style · ★☆☆

The statement 'if a triangle is equilateral then it is isosceles' is true. Which of the following must therefore also be true?

  1. IIf a triangle is isosceles then it is equilateral.
  2. IIIf a triangle is not isosceles then it is not equilateral.
  3. IIIIf a triangle is not equilateral then it is not isosceles.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Only the contrapositive (II) is logically equivalent to the original. I is the converse and III is the inverse; both are in fact false here.

7The logic of arguments · spec Arg2 · Paper 1 style · ★☆☆

Let \(P\) be the statement '\(x > 2\)' and \(Q\) the statement '\(x^2 > 4\)', where \(x\) is a real number. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

\(x > 2 \Rightarrow x^2 > 4\), so \(P\) is sufficient for \(Q\). But \(x = -3\) gives \(x^2 > 4\) without \(x > 2\), so \(P\) is not necessary.

8Chains of reasoning · spec Prf5 · Paper 1 style · ★☆☆

Each of \(100\) cards has a different integer from \(1\) to \(100\) written on it. What is the smallest number of cards that must be drawn (without looking) to be certain of having two cards whose numbers sum to \(101\)?

  1. A\(51\)
  2. B\(2\)
  3. C\(100\)
  4. D\(99\)
  5. E\(52\)
  6. F\(50\)
Worked solution

The \(50\) pairs \(\{1, 100\}, \{2, 99\}, \ldots, \{50, 51\}\) each sum to \(101\). Fifty cards (one from each pair) may avoid it; \(51\) cannot.

10Mathematical proof · spec Prf3 · Paper 1 style · ★☆☆

\(T_n\) denotes the \(n\)th triangular number \(\dfrac{n(n+1)}{2}\). A student observes \(T_1 + T_2 = 4\), \(T_2 + T_3 = 9\), \(T_3 + T_4 = 16\) and conjectures that \(T_n + T_{n+1}\) is always a perfect square. Which of the following proves the conjecture?

  1. A\(T_n + T_{n+1} = \dfrac{n(n+1) + (n+1)(n+2)}{2} = \dfrac{(n+1)(2n+2)}{2} = (n+1)^2\)
  2. B\(T_n + T_{n+1} = 2T_n + (n + 1)\), which is a square.
  3. CTriangular numbers are always squares.
  4. D\(T_4 + T_5 = 25\), which is a square, so the pattern continues.
  5. E\(T_{n+1} - T_n = n + 1\), so the sum is a square.
Worked solution

Only A is a general algebraic verification.

11Mathematical proof · spec Prf1 · Paper 1 style · ★☆☆

Which of the following claims is FALSE, and therefore can be disproved by a counterexample?

  1. AIf \(a > b\) then \(a + c > b + c\), for all real \(a, b, c\).
  2. BIf \(a > b\) then \(a^2 > b^2\), for all real \(a, b\).
  3. CIf \(a > b > 0\) then \(a^2 > b^2\).
  4. DIf \(a > b\) then \(a^3 > b^3\), for all real \(a, b\).
  5. EIf \(a > b\) then \(-a < -b\), for all real \(a, b\).
Worked solution

\(a = 1\), \(b = -2\): \(1 > -2\) but \(1 < 4\). The others are true.

12Exponentials and logarithms · spec MM5.2 · Paper 2 style · ★☆☆

Which of the following statements is/are true for all positive real \(x\) and \(y\)?

  1. I\(\log_{10}(x + y) = \log_{10} x + \log_{10} y\)
  2. II\(\log_{10}(xy)^2 = 2\log_{10} x + 2\log_{10} y\)
  3. III\(\log_{10} x - \log_{10} y = \log_{10} x \div \log_{10} y\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

II is correct: \(\log(xy)^2 = 2\log(xy) = 2\log x + 2\log y\). I and III confuse the laws: \(\log\) of a sum has no simple form, and a difference of logs is \(\log\) of a quotient, not a quotient of logs.

13Triangles, radians and sectors · spec MM4.1 · Paper 2 style · ★★☆

A triangle has sides \(a\), \(b\), \(c\) with \(a^2 + b^2 < c^2\). Which of the following statements is/are true?

  1. IThe angle opposite \(c\) is obtuse.
  2. II\(c\) is the longest side.
  3. IIIThe triangle cannot be isosceles.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Cosine rule: \(\cos C = \frac{a^2 + b^2 - c^2}{2ab} < 0\), so \(C\) is obtuse (I). The largest angle is opposite the longest side, so \(c\) is longest (II). III is false: \(a = b = 1\), \(c = 1.5\) works.

14Chains of reasoning · spec Prf5 · Paper 2 style · ★★☆

The positive integers \(a\), \(b\) and \(c\) satisfy \(a < b < c\) and \(a + b + c = 12\). Which of the following statements must be true?

  1. I\(a \leq 3\)
  2. II\(c \geq 5\)
  3. III\(b = 4\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Since \(a < b < c\), \(3a < 12\) so \(a \leq 3\) (I); \(3c > 12\) so \(c \geq 5\) (II). III fails: \(1 + 2 + 9 = 12\) has \(b = 2\).

15Differentiation · spec MM6.3 · Paper 2 style · ★★☆

The function \(f\) has \(f'(x) = (x - 1)(x - 3)^2\). Which of the following statements is/are true?

  1. I\(f\) has a local minimum at \(x = 1\).
  2. II\(f\) has a local maximum at \(x = 3\).
  3. III\(f\) is increasing for all \(x > 1\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(f'\) changes from negative to positive at \(x = 1\) (minimum). At \(x = 3\) the squared factor keeps \(f' \geq 0\) on both sides, so no turning point: II is false, and \(f' \geq 0\) for \(x > 1\) (zero only at \(3\)) makes III true.

16The logic of arguments · spec Arg4 · Paper 1 style · ★★☆

A statement reads: **for every positive integer \(n\), there is a prime \(p\) with \(n < p < 2n\).** Which of the following is its negation?

  1. AFor every positive integer \(n\), there is a prime \(p\) with \(p \leq n\) or \(p \geq 2n\).
  2. BThere is a positive integer \(n\) such that no prime \(p\) satisfies \(n < p < 2n\).
  3. CThere is a positive integer \(n\) and a prime \(p\) with \(p \leq n\) or \(p \geq 2n\).
  4. DThere is a prime \(p\) such that for every positive integer \(n\), \(n < p < 2n\) fails.
  5. EFor every positive integer \(n\), no prime \(p\) satisfies \(n < p < 2n\).
Worked solution

Negate the quantifiers in turn: 'for every \(n\), there exists \(p\) with ...' becomes 'there exists \(n\) such that for every prime \(p\), not ...', i.e. no prime lies strictly between \(n\) and \(2n\).

17Differentiation · spec MM6.1 · Paper 2 style · ★★☆

Which of the following statements is/are true for every function \(f\) that has a derivative at every real number?

  1. IIf \(f'(a) = 0\) then \(f\) has a maximum or a minimum at \(x = a\).
  2. IIIf \(f\) has a local minimum at \(x = a\) then \(f'(a) = 0\).
  3. IIIIf \(f'(x) > 0\) for all \(x\), then \(f(3) > f(2)\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I is false: \(f(x) = x^3\) has \(f'(0) = 0\) but no turning point. II is true (a stationary point is required at an interior local extremum of a differentiable function). III is true: a strictly increasing function has \(f(3) > f(2)\).

18Mathematical proof · spec Prf1 · Paper 1 style · ★★☆

Which of the following statements can be disproved by a single counterexample?

  1. IEvery prime number greater than \(2\) is odd.
  2. IIEvery integer of the form \(4k + 3\) is prime.
  3. IIIThere exists an even prime number.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Only a 'for all' statement can be disproved by one counterexample. I is true (no counterexample exists). II is false and \(k = 3\) (\(15\)) disproves it. III is an existence statement - a counterexample is meaningless; it is proved by the example \(2\).

19Simultaneous equations and inequalities · spec MM1.5 · Paper 2 style · ★★☆

Given that \(|2x - 3| < 5\), which of the following statements is/are true?

  1. I\(-1 < x < 4\)
  2. II\(x^2 < 16\)
  3. III\(x > -1\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(-5 < 2x - 3 < 5 \Rightarrow -1 < x < 4\), so I is true and III follows from I. For II: every \(x\) in \((-1, 4)\) has \(x^2 < 16\) (the largest possible \(|x|\) is just under \(4\)), so II is also true.

20Chains of reasoning · spec Prf5 · Paper 1 style · ★★★

The integers \(a, b, c\) satisfy \(a + b + c = 0\) and \(abc = 12\). Which of the following statements must be true?

  1. IExactly one of \(a, b, c\) is positive.
  2. II\(a^2 + b^2 + c^2\) is even.
  3. IIIOne of \(a, b, c\) is divisible by \(3\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(abc > 0\) means either none or exactly two of them are negative; they cannot all be positive with sum \(0\), so exactly two are negative and one positive (I). \(a^2 + b^2 + c^2 = (a+b+c)^2 - 2(ab + bc + ca) = -2(ab + bc + ca)\) is even (II). \(3\) is prime and divides \(abc\), so it divides one of them (III). (Example: \(-1, -3, 4\).)
