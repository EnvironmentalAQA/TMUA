1Quadratic functions · spec MM1.3 · Paper 1 style · ★☆☆

The roots of \(2x^2 + bx + 18 = 0\) are equal. Find the sum of the possible values of \(b\).

  1. A\(36\)
  2. B\(6\)
  3. C\(0\)
  4. D\(12\)
  5. E\(24\)
  6. F\(-12\)
Worked solution

\(b^2 - 144 = 0\), so \(b = \pm 12\); their sum is \(0\).

Answer C · Quadratic functions (MM1.3) · question QUA-12
2Sequences and series · spec MM2.2 · Paper 1 style · ★☆☆

An arithmetic series has first term \(5\) and common difference \(3\). Find the sum of the first \(40\) terms.

  1. A\(2440\)
  2. B\(2540\)
  3. C\(1270\)
  4. D\(2600\)
  5. E\(2500\)
  6. F\(2580\)
Worked solution

\(S_{40} = \frac{40}{2}\left(2\cdot5 + 39\cdot3\right) = 20(10 + 117) = 2540\).

Answer B · Sequences and series (MM2.2) · question SEQ-01
3Statistics · spec M6.3 · Paper 1 style · ★☆☆

A histogram has a bar for the class \(10 \leq x < 15\) of height (frequency density) \(3.2\) and a bar for \(15 \leq x < 25\) of height \(1.5\). What is the total frequency of these two classes?

  1. A\(15\)
  2. B\(23.5\)
  3. C\(31\)
  4. D\(4.7\)
  5. E\(16\)
  6. F\(47\)
Worked solution

Frequency \(=\) density \(\times\) width: \(3.2 \times 5 + 1.5 \times 10 = 16 + 15 = 31\).

Answer C · Statistics (M6.3) · question STA-02
4Exponentials and logarithms · spec MM5.2 · Paper 1 style · ★☆☆

Solve \(\log_2 (x^2 - 4) - \log_2 (x - 2) = 3\).

  1. A\(x = 2\)
  2. B\(x = 6\)
  3. C\(x = -10\) or \(x = 6\)
  4. D\(x = 8\)
  5. E\(x = 10\)
  6. F\(x = 4\)
Worked solution

For \(x > 2\): \(\log_2\frac{(x-2)(x+2)}{x-2} = \log_2(x + 2) = 3 \Rightarrow x + 2 = 8 \Rightarrow x = 6\).

Answer B · Exponentials and logarithms (MM5.2) · question LOG-15
5Differentiation · spec MM6.3 · Paper 1 style · ★☆☆

For what range of values of \(x\) is \(f(x) = 2x^3 - 15x^2 + 24x + 1\) decreasing?

  1. A\(-4 < x < -1\)
  2. B\(2 < x < 3\)
  3. C\(x > 1\)
  4. D\(x < 1\) or \(x > 4\)
  5. E\(x < 4\)
  6. F\(1 < x < 4\)
Worked solution

\(f'(x) = 6x^2 - 30x + 24 = 6(x - 1)(x - 4) < 0\) for \(1 < x < 4\).

Answer F · Differentiation (MM6.3) · question DIF-05
6Ratio, proportion and percentages · spec M3.11 · Paper 1 style · ★☆☆

\(\pounds 2000\) is invested at \(5\%\) compound interest per year. Which expression gives the amount after \(n\) years?

  1. A\(2000 \times 5^{n}\)
  2. B\(2000 + 100n\)
  3. C\(2000 \times 1.05^{n}\)
  4. D\(2000 \times 1.5^{n}\)
  5. E\(2000(1 + 0.05n)\)
  6. F\(2000 \times 0.05^{n}\)
Worked solution

Compound growth multiplies by \(1.05\) each year.

Answer C · Ratio, proportion and percentages (M3.11) · question RAT-10
7Differentiation · spec MM6.3 · Paper 1 style · ★☆☆

Find the minimum value of \(x + \dfrac{4}{x}\) for \(x > 0\).

  1. A\(5\)
  2. B\(2\sqrt2\)
  3. C\(4\)
  4. D\(0\)
  5. E\(2\)
  6. F\(8\)
Worked solution

Derivative \(1 - \frac{4}{x^2} = 0\) at \(x = 2\); value \(2 + 2 = 4\) (second derivative \(\frac{8}{x^3} > 0\), so a minimum).

Answer C · Differentiation (MM6.3) · question DIF-18
8Statistics · spec M6.3 · Paper 1 style · ★☆☆

Class A has \(20\) students with mean mark \(60\); class B has \(30\) students with mean mark \(70\). What is the mean mark of all \(50\) students?

  1. A\(68\)
  2. B\(65\)
  3. C\(62\)
  4. D\(67\)
  5. E\(64\)
  6. F\(66\)
Worked solution

\(\frac{1200 + 2100}{50} = \frac{3300}{50} = 66\).

Answer F · Statistics (M6.3) · question STA-09
9Ratio, proportion and percentages · spec M3.5 · Paper 1 style · ★☆☆

A recipe for \(12\) biscuits uses \(150\) g of flour and \(100\) g of butter. Ann has \(1\) kg of flour and \(500\) g of butter. What is the greatest number of biscuits she can make?

  1. A\(80\)
  2. B\(60\)
  3. C\(50\)
  4. D\(48\)
  5. E\(66\)
  6. F\(72\)
Worked solution

Flour allows \(\frac{1000}{150} \times 12 = 80\); butter allows \(\frac{500}{100} \times 12 = 60\). Butter is the limit: \(60\).

Answer B · Ratio, proportion and percentages (M3.5) · question RAT-14
10Functions and transformations · spec MM1.7 · Paper 1 style · ★☆☆

For which values of \(x\) is \(\sqrt{x^2} = -x\)?

  1. A\(x = 0\) only
  2. B\(x \geq 0\)
  3. C\(x \leq 0\)
  4. D\(x < 0\) only
  5. Eall real \(x\)
  6. Fno real \(x\)
Worked solution

\(\sqrt{x^2} = |x|\), and \(|x| = -x\) exactly when \(x \leq 0\).

Answer C · Functions and transformations (MM1.7) · question FUN-08

12Integration · spec MM7.3 · Paper 1 style · ★☆☆

Given that \(\displaystyle\int_{0}^{a} (2x + 1)\,dx = 12\) where \(a > 0\), find \(a\).

  1. A\(4\)
  2. B\(12\)
  3. C\(2\)
  4. D\(3\)
  5. E\(\sqrt{12}\)
  6. F\(6\)
Worked solution

\(a^2 + a = 12 \Rightarrow (a + 4)(a - 3) = 0 \Rightarrow a = 3\).

13Circles and circle theorems · spec MM3.2 · Paper 1 style · ★☆☆

A circle passes through \((0, 0)\), \((6, 0)\) and \((0, 8)\). Find the coordinates of its centre.

  1. A\((5, 5)\)
  2. B\((2, 3)\)
  3. C\((4, 3)\)
  4. D\((6, 8)\)
  5. E\((3, 4)\)
  6. F\((3, 3)\)
Worked solution

The triangle has a right angle at the origin, so \((6, 0)\)-\((0, 8)\) is a diameter; the centre is its midpoint \((3, 4)\).

14Simultaneous equations and inequalities · spec MM1.4 · Paper 1 style · ★☆☆

The line \(y = x + k\) meets the circle \(x^2 + y^2 = 8\) at exactly one point. Find the possible values of \(k\).

  1. A\(k = \pm 2\sqrt{2}\)
  2. B\(k = \pm 8\)
  3. C\(k = \pm 4\)
  4. D\(k = \pm \sqrt{8}\)
  5. E\(k = 4\) only
  6. F\(k = \pm 2\)
Worked solution

\(x^2 + (x+k)^2 = 8 \Rightarrow 2x^2 + 2kx + k^2 - 8 = 0\). Tangent when \(4k^2 - 8(k^2 - 8) = 0 \Rightarrow -4k^2 + 64 = 0 \Rightarrow k = \pm 4\).

Answer C · Simultaneous equations and inequalities (MM1.4) · question SIM-04
15Straight lines · spec MM3.1 · Paper 1 style · ★☆☆

A line passes through \((1, 2)\) with gradient \(m\). It crosses the \(x\)-axis at \(A\) and the \(y\)-axis at \(B\), and the midpoint of \(AB\) is \((1, 2)\). Find \(m\).

  1. A\(-2\)
  2. B\(\dfrac12\)
  3. C\(2\)
  4. D\(-4\)
  5. E\(-\dfrac12\)
  6. F\(-1\)
Worked solution

Midpoint \((1, 2)\) means \(A = (2, 0)\) and \(B = (0, 4)\). Gradient \(= \frac{4 - 0}{0 - 2} = -2\).

Answer A · Straight lines (MM3.1) · question LIN-14
16Triangles, radians and sectors · spec MM4.2 · Paper 1 style · ★★☆

A circle has radius \(r\). A sector of angle \(\theta\) radians has the same area as the segment cut off by a chord that subtends an angle of \(\dfrac{\pi}{2}\) at the centre. Find \(\theta\).

  1. A\(\dfrac{\pi}{2} - 1\)
  2. B\(\dfrac{\pi}{4}\)
  3. C\(\dfrac{\pi}{4} - \dfrac12\)
  4. D\(1\)
  5. E\(\pi - 2\)
  6. F\(\dfrac{\pi}{2} - \dfrac12\)
Worked solution

Segment area \(= \frac12 r^2\left(\frac\pi2 - \sin\frac\pi2\right) = \frac12 r^2\left(\frac\pi2 - 1\right)\). Sector area \(\frac12 r^2\theta\). So \(\theta = \frac\pi2 - 1\).

Answer A · Triangles, radians and sectors (MM4.2) · question TRI-11
17Circles and circle theorems · spec MM3.2 · Paper 1 style · ★★☆

Find the complete set of values of \(k\) for which \(x^2 + y^2 + 2kx - 4y + 3k + 4 = 0\) represents a circle.

  1. A\(k > 3\)
  2. B\(0 < k < 3\)
  3. C\(k < -3\) or \(k > 0\)
  4. D\(k < 0\) or \(k > 3\)
  5. E\(-3 < k < 0\)
  6. Fall real \(k\)
Worked solution

\((x + k)^2 + (y - 2)^2 = k^2 + 4 - 3k - 4 = k^2 - 3k = k(k - 3)\). A circle needs a positive right-hand side: \(k < 0\) or \(k > 3\).

Answer D · Circles and circle theorems (MM3.2) · question CIR-02
18Sequences and series · spec MM2.2 · Paper 1 style · ★★☆

The sum of the first \(n\) natural numbers is \(S\). The sum of the first \(2n\) natural numbers is \(kS\). Which of the following is true?

  1. A\(k = \dfrac{4n + 2}{n}\)
  2. B\(k = 4\) for all \(n\)
  3. C\(k = \dfrac{2(2n+1)}{n+1}\)
  4. D\(k = 2\) for all \(n\)
  5. E\(k = 4 - \dfrac{2}{n}\)
Worked solution

\(S = \frac{n(n+1)}{2}\) and the sum to \(2n\) is \(\frac{2n(2n+1)}{2} = n(2n+1)\). So \(k = \dfrac{n(2n+1)}{n(n+1)/2} = \dfrac{2(2n+1)}{n+1}\).

Answer C · Sequences and series (MM2.2) · question SEQ-11
19Triangles, radians and sectors · spec MM4.1 · Paper 1 style · ★★☆

Triangle \(PQR\) has area \(10\sqrt{3}\), \(PQ = 8\) and \(PR = 5\). Given that angle \(QPR\) is obtuse, find \(QR\).

  1. A\(13\)
  2. B\(\sqrt{89}\)
  3. C\(\sqrt{89 + 40\sqrt{3}}\)
  4. D\(\sqrt{129}\)
  5. E\(7\)
  6. F\(\sqrt{109}\)
Worked solution

\(\frac12\cdot8\cdot5\sin P = 10\sqrt3 \Rightarrow \sin P = \frac{\sqrt3}{2}\), and \(P\) obtuse gives \(P = 120^\circ\). \(QR^2 = 64 + 25 - 80\cos120^\circ = 89 + 40 = 129\).

Answer D · Triangles, radians and sectors (MM4.1) · question TRI-04
20Integration · spec MM7.1 · Paper 1 style · ★★☆

The region bounded by \(y = 4 - x^2\), the \(x\)-axis and the lines \(x = 0\) and \(x = 3\) is shaded. Find the total shaded area.

  1. A\(3\)
  2. B\(\dfrac{7}{3}\)
  3. C\(\dfrac{16}{3}\)
  4. D\(\dfrac{25}{3}\)
  5. E\(\dfrac{23}{3}\)
  6. F\(9\)
Worked solution

From \(0\) to \(2\) the curve is above the axis: \(\int_0^2 (4 - x^2)\,dx = 8 - \frac83 = \frac{16}{3}\). From \(2\) to \(3\) it is below: \(\left|\int_2^3 (4 - x^2)\,dx\right| = \left|(12 - 9) - \frac{16}{3}\right| = \frac73\). Total \(\frac{23}{3}\).

Answer E · Integration (MM7.1) · question INT-11
