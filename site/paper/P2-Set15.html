1Exponentials and logarithms · spec MM5.2 · Paper 1 style · ★☆☆

Solve \(\log_2 x + \log_4 x = 6\). (You may use \(\log_4 x = \dfrac{1}{2}\log_2 x\).)

  1. A\(x = 8\)
  2. B\(x = 2^{6}\)
  3. C\(x = 16\)
  4. D\(x = 64\)
  5. E\(x = 4\)
  6. F\(x = 32\)
Worked solution

\(\frac32\log_2 x = 6 \Rightarrow \log_2 x = 4 \Rightarrow x = 16\).

2Trigonometric functions and equations · spec MM4.6 · Paper 1 style · ★☆☆

How many solutions does \(\sin 2x = \dfrac{1}{2}\) have for \(0 \leq x < 2\pi\)?

  1. A\(2\)
  2. B\(6\)
  3. C\(4\)
  4. D\(8\)
  5. E\(1\)
  6. F\(3\)
Worked solution

\(2x\) runs over \([0, 4\pi)\), which contains two full periods of \(\sin\), each giving two solutions: \(4\) in total.

4Mathematical proof · spec Prf1 · Paper 1 style · ★☆☆

Which of the following is a counterexample to the claim **'if \(n\) is a positive integer, then \(2^n + 1\) is prime'**?

  1. A\(n = 8\)
  2. B\(n = 1\)
  3. C\(n = 4\)
  4. D\(n = 3\)
  5. E\(n = 2\)
Worked solution

\(2^3 + 1 = 9 = 3 \times 3\) is not prime. (\(n = 1, 2, 4, 8\) give \(3, 5, 17, 257\), all prime.)

5Angles, polygons, congruence and vectors · spec M5.3 · Paper 2 style · ★☆☆

Which of the following statements is/are true?

  1. IEvery rhombus is a parallelogram.
  2. IIEvery rectangle is a rhombus.
  3. IIIThe diagonals of a kite are perpendicular.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

A rhombus has two pairs of parallel sides (I). A rectangle need not have equal sides (II false). The diagonals of a kite cross at right angles (III).

6Mathematical proof · spec Prf2 · Paper 1 style · ★☆☆

It is given that for all real \(x\): if \(f(x) > 0\) then \(g(x) > 0\). It is also known that \(g(2) = -1\). What can be deduced?

  1. A\(f(2) < 0\)
  2. B\(f(2) = 0\)
  3. C\(f(2) > 0\)
  4. D\(f(2) \leq 0\)
  5. Enothing about \(f(2)\)
Worked solution

Contrapositive: if \(g(x) \leq 0\) then \(f(x) \leq 0\). Since \(g(2) = -1 \leq 0\), \(f(2) \leq 0\) (it could be \(0\) or negative).

7Sequences and series · spec MM2.3 · Paper 2 style · ★☆☆

A geometric series has first term \(a \neq 0\) and common ratio \(r\). \(P\): '\(-1 < r < 1\)'. \(Q\): 'the series has a sum to infinity'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

A geometric series converges if and only if \(|r| < 1\), which is exactly \(-1 < r < 1\).

8Chains of reasoning · spec Prf5 · Paper 1 style · ★☆☆

The sum of \(5\) consecutive odd numbers is \(S\). Which of the following is always a factor of \(S\)?

  1. A\(4\)
  2. B\(3\)
  3. C\(10\)
  4. D\(25\)
  5. E\(15\)
  6. F\(5\)
Worked solution

\((m - 4) + (m - 2) + m + (m + 2) + (m + 4) = 5m\) where \(m\) is the middle (odd) number; \(5m\) is odd, so \(10\) is never a factor.

Answer F · Chains of reasoning (Prf5) · question RSN-16
9The logic of arguments · spec Arg2 · Paper 1 style · ★☆☆

Let \(P\): 'the quadrilateral \(ABCD\) is a square' and \(Q\): 'the quadrilateral \(ABCD\) has four equal sides'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

A square has four equal sides (\(P \Rightarrow Q\), sufficient), but a rhombus that is not a square shows \(Q\) does not imply \(P\) (not necessary).

10Identifying errors in proofs · spec Err2 · Paper 2 style · ★☆☆

A student solves \(x^2 - 5x + 6 > 0\) as follows.

  1. I\(x^2 - 5x + 6 = (x - 2)(x - 3)\).
  2. IISo \((x - 2)(x - 3) > 0\).
  3. IIISo \(x - 2 > 0\) and \(x - 3 > 0\).
  4. IVSo \(x > 3\).

Which of the following is correct?

  1. AThe first error is on line III: a product is positive when both factors are positive or both are negative, so \(x < 2\) is missed.
  2. BThe solution is completely correct.
  3. CThe first error is on line I.
  4. DThe first error is on line IV: it should be \(x > 2\).
  5. EThe first error is on line II.
Worked solution

The full solution set is \(x < 2\) or \(x > 3\).

11Straight lines · spec MM3.1 · Paper 2 style · ★☆☆

Two distinct lines have equations \(y = m_1 x + c_1\) and \(y = m_2 x + c_2\). Which of the following statements is/are true?

  1. IIf \(m_1 m_2 = -1\) then the lines meet at exactly one point.
  2. IIIf \(m_1 = m_2\) then the lines do not meet.
  3. IIIIf the lines meet on the \(y\)-axis then \(c_1 = c_2\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: perpendicular lines are not parallel, so they meet once. II: equal gradients and distinct lines means parallel and different, so no intersection. III: on the \(y\)-axis \(x = 0\), so \(y = c_1 = c_2\).

12The logic of arguments · spec Arg1 · Paper 1 style · ★☆☆

Consider the statement: **if \(a\) and \(b\) are irrational, then \(a + b\) is irrational.** Which of the following pairs is a counterexample?

  1. A\(a = 1\), \(b = -1\)
  2. B\(a = \sqrt2\), \(b = -\sqrt2\)
  3. C\(a = \pi\), \(b = \sqrt2\)
  4. D\(a = \sqrt2\), \(b = 2\sqrt2\)
  5. E\(a = \sqrt2\), \(b = \sqrt3\)
Worked solution

A counterexample needs the hypothesis true (both irrational) and the conclusion false (\(a + b\) rational): \(\sqrt2 + (-\sqrt2) = 0\).

14Functions and transformations · spec MM1.7 · Paper 2 style · ★★☆

Let \(f(x) = \sqrt{x - 3}\) for \(x \geq 3\) and \(g(x) = x^2 + 3\). Which of the following statements is/are true?

  1. I\(g(f(x)) = x\) for all \(x \geq 3\)
  2. II\(f(g(x)) = x\) for all real \(x\)
  3. III\(f(g(x)) = |x|\) for all real \(x\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: \(g(f(x)) = (\sqrt{x-3})^2 + 3 = x\) for \(x \geq 3\): true. \(f(g(x)) = \sqrt{x^2} = |x|\), so II fails (e.g. \(x = -1\)) and III is true.

Answer F · Functions and transformations (MM1.7) · question FUN-12
15Indices and surds · spec MM1.1 · Paper 2 style · ★★☆

\(a\) and \(b\) are positive real numbers. Which of the following statements is/are true?

  1. IIf \(a^2 = b^2\) then \(a = b\).
  2. IIIf \(2^a = 2^b\) then \(a = b\).
  3. IIIIf \(a^b = 1\) then \(a = 1\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I holds because \(a, b > 0\) rules out \(a = -b\). II holds because \(2^x\) is one-to-one. III: for positive \(a\) and \(b\), \(a^b = 1\) gives \(b\log a = 0\), so \(\log a = 0\) and \(a = 1\). All three are true.

16Binomial expansion · spec MM2.4 · Paper 2 style · ★★☆

The expansion of \(\left(2x - \dfrac{1}{x^2}\right)^{9}\) contains a term in \(x^{k}\) for each of which of the following values of \(k\)?

  1. I\(k = 0\)
  2. II\(k = 3\)
  3. III\(k = -6\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

General term: \(\binom9r (2x)^{9-r}(-x^{-2})^r\) has power \(9 - r - 2r = 9 - 3r\), which takes values \(9, 6, 3, 0, -3, \ldots, -18\). \(k = 0\) needs \(r = 3\): yes. \(k = 3\) needs \(r = 2\): yes. \(k = -6\) needs \(r = 5\): yes. All three.

17Identifying errors in proofs · spec Err1 · Paper 1 style · ★★☆

Claim: for all positive real \(x\), \(x + \dfrac{1}{x} \geq 2\).

  1. ISuppose \(x + \dfrac1x \geq 2\).
  2. IIMultiply by \(x > 0\): \(x^2 + 1 \geq 2x\).
  3. IIISo \(x^2 - 2x + 1 \geq 0\), i.e. \((x - 1)^2 \geq 0\), which is true.
  4. IVHence the claim is proved.

Which of the following best describes the argument?

  1. AThe argument assumes what it is trying to prove (line I); it would be valid if the steps were reversed, starting from \((x - 1)^2 \geq 0\).
  2. BThe argument is completely correct as written.
  3. CThe first error is on line II: multiplying by \(x\) reverses the inequality.
  4. DThe first error is on line III.
  5. EThe claim is false.
Worked solution

Starting from the conclusion and reaching a truth does not prove the conclusion unless every step is reversible and the argument is presented in the forward direction. Here the steps are reversible, so the repair is to write it backwards.

Answer A · Identifying errors in proofs (Err1) · question ERR-13
18Functions and transformations · spec MM8.2 · Paper 2 style · ★★☆

\(f(x) = x^2 + 1\). Which of the following statements is/are true?

  1. I\(f(f(x)) = x^4 + 2x^2 + 2\) for all \(x\)
  2. II\(f(x + 1) = f(x) + 1\) for all \(x\)
  3. III\(f(2x) = 4f(x) - 3\) for all \(x\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: \(f(f(x)) = (x^2+1)^2 + 1 = x^4 + 2x^2 + 2\): true. II: \(f(x+1) = x^2 + 2x + 2 \neq x^2 + 2\): false. III: \(f(2x) = 4x^2 + 1\) and \(4f(x) - 3 = 4x^2 + 1\): true.

Answer F · Functions and transformations (MM8.2) · question FUN-10
19Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

Three statements are made about a positive integer \(N\):

  • \(N\) is a perfect square.
  • \(N\) is a multiple of \(6\).
  • \(N\) is less than \(50\).

Exactly two of the statements are true. Which of the following could NOT be \(N\)?

  1. A\(144\)
  2. B\(12\)
  3. C\(36\)
  4. D\(48\)
  5. E\(16\)
  6. F\(25\)
Worked solution

\(36\) makes all three statements true, not exactly two. Each of the others makes exactly two true: \(16\) and \(25\) (square, \(< 50\)), \(48\) and \(12\) (multiple of \(6\), \(< 50\)), \(144\) (square, multiple of \(6\)).

Answer C · Chains of reasoning (Prf5) · question RSN-06
20Chains of reasoning · spec Prf5 · Paper 1 style · ★★★

How many ordered pairs of positive integers \((m, n)\) satisfy \(\dfrac{1}{m} + \dfrac{1}{n} = \dfrac{1}{4}\)?

  1. A\(4\)
  2. B\(3\)
  3. C\(2\)
  4. D\(6\)
  5. E\(8\)
  6. F\(5\)
Worked solution

\(4n + 4m = mn \Rightarrow (m - 4)(n - 4) = 16\). Positive factor pairs of \(16\) as ordered pairs: \((1,16), (2,8), (4,4), (8,2), (16,1)\): five. (Negative factor pairs would make \(m\) or \(n\) non-positive.)
