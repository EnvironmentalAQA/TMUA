1Quadratic functions · spec MM1.3 · Paper 1 style · ★☆☆

Find the range of values of \(x\) for which \(x^2 - 7x + 10 < 0\) and \(x^2 - 4 > 0\).

  1. A\(2 < x < 5\)
  2. B\(-2 < x < 2\)
  3. C\(x > 5\)
  4. D\(x < -2\)
  5. E\(2 < x < 5\) or \(x < -2\)
  6. Fno values
Worked solution

\((x-2)(x-5) < 0\) gives \(2 < x < 5\); \(x^2 > 4\) gives \(x < -2\) or \(x > 2\). The intersection is \(2 < x < 5\).

2Differentiation · spec MM6.3 · Paper 1 style · ★☆☆

Find the equation of the normal to the curve \(y = \sqrt{x}\) at the point \((4, 2)\).

  1. A\(y = -4x + 16\)
  2. B\(y = -4x + 18\)
  3. C\(y = -4x + 2\)
  4. D\(y = \dfrac14 x + 1\)
  5. E\(y = -\dfrac14 x + 3\)
  6. F\(y = 4x - 14\)
Worked solution

\(y' = \frac{1}{2\sqrt x} = \frac14\) at \(x = 4\), so the normal has gradient \(-4\): \(y - 2 = -4(x - 4)\), i.e. \(y = -4x + 18\).

4Integration · spec MM7.6 · Paper 1 style · ★☆☆

The gradient of a curve at \((x, y)\) is \(3\sqrt{x}\) and the curve passes through \((4, 20)\). Find the \(y\)-intercept of the curve.

  1. A\(12\)
  2. B\(20\)
  3. C\(4\)
  4. D\(8\)
  5. E\(-4\)
  6. F\(0\)
Worked solution

\(y = 2x^{3/2} + c\); \(20 = 16 + c \Rightarrow c = 4\). The \(y\)-intercept is \(4\).

Evaluate \(\displaystyle\sum_{k=1}^{10} 3 \times 2^{k}\).

  1. A\(6141\)
  2. B\(3069\)
  3. C\(3072\)
  4. D\(3066\)

The distance-time graph of a journey is a straight line from \((0, 0)\) to \((2, 60)\), then horizontal to \((3, 60)\), then a straight line to \((5, 0)\) (time in hours, distance from home in km). What was the average speed for the whole journey?

  1. A\(0\) km/h
  2. B\(12\) km/h
  3. C\(24\) km/h
  4. D\(20\) km/h
  5. E\(30\) km/h
  6. F\(40\) km/h

7Pythagoras, mensuration and 3D · spec M5.7 · Paper 1 style · ★☆☆

A ladder of length \(6.5\) m leans against a vertical wall with its foot \(2.5\) m from the wall on horizontal ground. How far up the wall does it reach?

  1. A\(7\) m
  2. B\(5\) m
  3. C\(4\) m
  4. D\(5.5\) m
  5. E\(6\) m
  6. F\(\sqrt{48.5}\) m
Worked solution

8Straight lines · spec MM3.1 · Paper 1 style · ★☆☆

The line \(ax + by = 12\) has \(x\)-intercept \(3\) and \(y\)-intercept \(-4\). Find \(a - b\).

  1. A\(12\)
  2. B\(7\)
  3. C\(-1\)
  4. D\(0\)
  5. E\(-7\)
  6. F\(1\)
Worked solution

\((3, 0)\): \(3a = 12 \Rightarrow a = 4\). \((0, -4)\): \(-4b = 12 \Rightarrow b = -3\). \(a - b = 7\).

9Binomial expansion · spec MM2.4 · Paper 1 style · ★☆☆

In the expansion of \((1 + x)^n\), the coefficients of \(x^4\) and \(x^5\) are equal. Find \(n\).

  1. A\(20\)
  2. B\(5\)
  3. C\(11\)
  4. D\(9\)
  5. E\(10\)
  6. F\(8\)
Worked solution

\(\binom n4 = \binom n5\) requires \(4 + 5 = n\) (by symmetry \(\binom nr = \binom n{n-r}\)), so \(n = 9\).

11Functions and transformations · spec MM8.3 · Paper 1 style · ★☆☆

The line \(y = mx + c\) passes through \((2, 7)\). If \(m\) is increased by \(1\) and \(c\) is decreased by \(2\), the new line passes through \((2, k)\). Find \(k\).

  2. B\(7\)
  3. C\(5\)
  4. D\(9\)

13Graphs of functions · spec MM8.7 · Paper 1 style · ★☆☆

The line \(y = mx\) meets the curve \(y = x^3 - x\) at three distinct points. Find the complete set of values of \(m\).

  1. A\(m < -1\)
  2. B\(-1 < m < 0\)
  3. C\(m > 1\)
  4. D\(m > 0\)
  5. E\(m > -1\)
  6. Fall real \(m\)
Worked solution

\(x^3 - x - mx = x(x^2 - (1 + m)) = 0\): three distinct roots iff \(1 + m > 0\), i.e. \(m > -1\).

14Differentiation · spec MM6.3 · Paper 1 style · ★☆☆

Find the coordinates of the stationary points of \(y = x^3 - 3x^2 - 9x + 5\) and state their nature.

  1. Amaximum at \((1, -6)\), minimum at \((-3, -22)\)
  2. Bminimum at \((-1, 10)\), maximum at \((3, -22)\)
  3. Cmaximum at \((-1, 10)\), minimum at \((3, -22)\)
  4. Dmaximum at \((-1, 0)\), minimum at \((3, -32)\)
  5. Emaximum at \((-1, 10)\) only
Worked solution

\(y' = 3x^2 - 6x - 9 = 3(x - 3)(x + 1)\). \(y'' = 6x - 6\): negative at \(x = -1\) (max, \(y = -1 - 3 + 9 + 5 = 10\)), positive at \(x = 3\) (min, \(y = 27 - 27 - 27 + 5 = -22\)).

Answer C · Differentiation (MM6.3) · question DIF-02
15Triangles, radians and sectors · spec MM4.1 · Paper 1 style · ★★☆

A vertical pole \(BT\) stands on horizontal ground. From a point \(A\) on the ground the angle of elevation of \(T\) is \(30^\circ\); from a point \(C\) on the ground, \(20\) m closer to the pole than \(A\) and in line with \(A\) and \(B\), the angle of elevation is \(60^\circ\). Find the height of the pole.

  1. A\(10\) m
  2. B\(20\sqrt{3}\) m
  3. C\(15\) m
  4. D\(10\sqrt{3}\) m
  5. E\(\dfrac{20}{\sqrt3}\) m
  6. F\(30\) m
Worked solution

Let the height be \(h\). \(AB = h\sqrt3\) and \(CB = \frac{h}{\sqrt3}\). \(AB - CB = 20 \Rightarrow h\left(\sqrt3 - \frac1{\sqrt3}\right) = \frac{2h}{\sqrt3} = 20 \Rightarrow h = 10\sqrt3\).

Answer D · Triangles, radians and sectors (MM4.1) · question TRI-14
16Polynomials, factor and remainder theorems · spec MM1.6 · Paper 1 style · ★★☆

For which value of \(k\) does \(x^2 - x + k\) divide exactly into \(x^3 - 2x^2 + 3x - 4\)? (Assume such a value exists.)

  1. A\(-2\)
  2. B\(3\)
  3. C\(4\)
  4. D\(2\)
  5. E\(1\)
  6. Fno such value exists
Worked solution

Try \(x^3 - 2x^2 + 3x - 4 = (x^2 - x + k)(x + m)\): comparing \(x^2\): \(m - 1 = -2 \Rightarrow m = -1\). Then \(x\): \(k - m = k + 1 = 3 \Rightarrow k = 2\). Constant: \(km = -2 \neq -4\). No value of \(k\) works.

Answer F · Polynomials, factor and remainder theorems (MM1.6) · question POL-16
17Sequences and series · spec MM2.3 · Paper 1 style · ★★☆

The first three terms of a geometric sequence are \(x\), \(x + 6\) and \(x + 15\). Find the fourth term.

  1. A\(\dfrac{81}{2}\)
  2. B\(\dfrac{125}{2}\)
  3. C\(\dfrac{75}{2}\)
  4. D\(\dfrac{225}{4}\)
  5. E\(\dfrac{125}{4}\)
  6. F\(45\)
Worked solution

Geometric: \((x+6)^2 = x(x+15) \Rightarrow x^2 + 12x + 36 = x^2 + 15x \Rightarrow x = 12\). The terms are \(12, 18, 27\) with ratio \(\frac32\), so the fourth term is \(27 \times \frac32 = \frac{81}{2}\).

Answer A · Sequences and series (MM2.3) · question SEQ-19
18Quadratic functions · spec MM1.3 · Paper 1 style · ★★☆

The equation \(x^2 + ax + b = 0\) has roots \(3\) and \(-5\). The equation \(x^2 + bx + a = 0\) has roots \(p\) and \(q\). Find \(p^2 + q^2\).

  1. A\(229\)
  2. B\(195\)
  3. C\(4\)
  4. D\(221\)
  5. E\(225\)
  6. F\(255\)
Worked solution

Sum of roots \(3 + (-5) = -a\), so \(a = 2\); product \(-15 = b\). Then \(x^2 - 15x + 2 = 0\) has \(p + q = 15\) and \(pq = 2\), so \(p^2 + q^2 = 15^2 - 2(2) = 221\).

Answer D · Quadratic functions (MM1.3) · question QUA-22

20Triangles, radians and sectors · spec MM4.2 · Paper 1 style · ★★☆

The perimeter of a sector of radius \(r\) and angle \(\theta\) radians is \(20\), and its area is \(16\). Find the possible values of \(r\).

  1. A\(4\) only
  2. B\(8\) only
  3. C\(1\) or \(16\)
  4. D\(2\) or \(8\)
  5. E\(4\) or \(8\)
  6. F\(2\) or \(4\)
Worked solution

\(2r + r\theta = 20\) and \(\frac12 r^2\theta = 16\). From the first \(r\theta = 20 - 2r\); then \(\frac12 r(20 - 2r) = 16 \Rightarrow r^2 - 10r + 16 = 0 \Rightarrow r = 2\) or \(8\).

Answer D · Triangles, radians and sectors (MM4.2) · question TRI-08
