1Simultaneous equations and inequalities · spec MM1.4 · Paper 1 style · ★☆☆

Solve \(xy = 6\) and \(x - y = 1\). What is the sum of all possible values of \(x + y\)?

  1. A\(10\)
  2. B\(5\)
  3. C\(-5\)
  4. D\(7\)
  5. E\(1\)
  6. F\(0\)
Worked solution

\(x = y + 1\): \(y^2 + y - 6 = 0 \Rightarrow (y+3)(y-2) = 0\). Solutions \((3, 2)\) with \(x + y = 5\) and \((-2, -3)\) with \(x + y = -5\). The sum is \(0\).

2Indices and surds · spec MM1.1 · Paper 1 style · ★☆☆

Given that \(2^{x} = 5\) and \(2^{y} = 20\), find the value of \(2^{2x - y}\).

  1. A\(\dfrac{1}{4}\)
  2. B\(\dfrac{4}{5}\)
  3. C\(\dfrac{5}{4}\)
  4. D\(-10\)
  5. E\(\dfrac{25}{2}\)
  6. F\(5\)
Worked solution

\(2^{2x - y} = \dfrac{(2^x)^2}{2^y} = \dfrac{25}{20} = \dfrac54\).

3Differentiation · spec MM6.3 · Paper 1 style · ★☆☆

Find the sum of the \(y\)-coordinates of the stationary points of the curve \(y = 2x^3 - 9x^2 + 12x - 3\).

  1. A\(2\)
  2. B\(0\)
  3. C\(5\)
  4. D\(4\)
  5. E\(3\)
  6. F\(1\)
Worked solution

\(y' = 6x^2 - 18x + 12 = 6(x - 1)(x - 2)\): stationary points at \(x = 1\) (\(y = 2 - 9 + 12 - 3 = 2\)) and \(x = 2\) (\(y = 16 - 36 + 24 - 3 = 1\)). Sum \(3\).

4The logic of arguments · spec Arg1 · Paper 1 style · ★☆☆

Let \(x\) be a real number. Which of the following statements is equivalent to **'\(x \geq 2\) if and only if \(x^3 \geq 8\)'**?

  1. A\(x^3 \geq 8 \Rightarrow x \geq 2\)
  2. B(\(x \geq 2 \Rightarrow x^3 \geq 8\)) and (\(x^3 \geq 8 \Rightarrow x \geq 2\))
  3. C(\(x < 2 \Rightarrow x^3 \geq 8\)) or (\(x^3 < 8 \Rightarrow x \geq 2\))
  4. D\(x \geq 2 \Rightarrow x^3 \geq 8\)
  5. E\(x \geq 2\) or \(x^3 \geq 8\)
Worked solution

'If and only if' is the conjunction of the implication and its converse.

5Mathematical proof · spec Prf1 · Paper 2 style · ★☆☆

Consider the claim: **if \(n\) is a positive integer then \(n^2 + n + 1\) is odd.** Which of the following is a valid proof?

  1. A\(n^2 + n = n(n + 1)\) is even, being the product of consecutive integers, so \(n^2 + n + 1\) is even plus one, which is odd.
  2. B\(n^2 + n + 1\) cannot be factorised, so it is odd.
  3. CFor \(n = 1, 2, 3\) the values are \(3, 7, 13\), all odd, so the claim holds.
  4. DSuppose \(n^2 + n + 1\) is even. Then \(n\) is even, which is a contradiction.
  5. EIf \(n\) is odd then \(n^2\) is odd and \(n\) is odd, so \(n^2 + n + 1\) is odd.
Worked solution

A is a direct general argument. B only checks cases; C is irrelevant; D is correct for odd \(n\) but says nothing about even \(n\); E does not reach a contradiction.

6Identifying errors in proofs · spec Err2 · Paper 1 style · ★☆☆

Claim: if \(a > b\) then \(\dfrac{1}{a} < \dfrac{1}{b}\).

  1. ISuppose \(a > b\).
  2. IIDividing both sides by \(ab\): \(\dfrac{1}{b} > \dfrac{1}{a}\).
  3. IIISo \(\dfrac1a < \dfrac1b\).

Which of the following is correct?

  1. AThe claim is false in general and the first error is on line II, since \(ab\) may be negative or zero.
  2. BThe claim and proof are correct.
  3. CThe first error is on line III.
  4. DThe claim is true but the first error is on line I.
  5. EThe claim is false and the first error is on line III.
Worked solution

\(a = 1\), \(b = -1\): \(a > b\) but \(\frac1a = 1 > -1 = \frac1b\). Dividing by \(ab\) without knowing its sign is invalid (and \(b = 0\) would be division by zero).

Answer A · Identifying errors in proofs (Err2) · question ERR-10
7Mathematical proof · spec Prf1 · Paper 1 style · ★☆☆

Prove by cases that \(n^3 - n\) is divisible by \(3\) for every integer \(n\). Which set of cases is both sufficient and necessary to consider?

  1. A\(n = 3k + 1\), \(n = 3k + 2\)
  2. B\(n\) even, \(n\) odd
  3. C\(n\) positive, \(n\) zero, \(n\) negative
  4. D\(n = 3k\), \(n = 3k + 1\), \(n = 3k + 2\)
  5. E\(n\) prime, \(n\) not prime
Worked solution

\(n^3 - n = (n - 1)n(n + 1)\) is a product of three consecutive integers; splitting by remainder on division by \(3\) shows one factor is a multiple of \(3\) in every case.

8Identifying errors in proofs · spec Err2 · Paper 1 style · ★☆☆

A student solves \(2\cos^2 x = \cos x\) for \(0 \leq x < 2\pi\).

  1. IDivide both sides by \(\cos x\): \(2\cos x = 1\).
  2. IISo \(\cos x = \dfrac12\).
  3. IIISo \(x = \dfrac{\pi}{3}\) or \(x = \dfrac{5\pi}{3}\).

How many solutions has the student missed, and where is the first error?

  1. ATwo solutions missed; the first error is on line I.
  2. BNo solutions missed; the working is correct.
  3. COne solution missed; the first error is on line III.
  4. DTwo solutions missed; the first error is on line III.
  5. EOne solution missed; the first error is on line I.
Worked solution

Dividing by \(\cos x\) loses \(\cos x = 0\), i.e. \(x = \frac\pi2\) and \(x = \frac{3\pi}{2}\): two solutions.

9Simultaneous equations and inequalities · spec MM1.5 · Paper 2 style · ★☆☆

\(x\) is a real number. \(P\): '\(x^2 < 4\)'. \(Q\): '\(x < 2\)'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

\(x^2 < 4\) means \(-2 < x < 2\), which implies \(x < 2\) (sufficient); but \(x = -5\) satisfies \(Q\) and not \(P\) (not necessary).

10Graphs of functions · spec MM8.1 · Paper 2 style · ★☆☆

Which of the following statements about the graph of \(y = |2x - 4|\) is/are true?

  1. IIt meets the \(x\)-axis at exactly one point.
  2. IIIt is symmetric about the line \(x = 2\).
  3. IIIIt lies entirely on or above the line \(y = 0\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(|2x - 4| = 0\) only at \(x = 2\) (I). \(|2x - 4| = 2|x - 2|\) is symmetric about \(x = 2\) (II). A modulus is never negative (III).

11Exponentials and logarithms · spec MM5.2 · Paper 2 style · ★★☆

Which of the following is a counterexample to the claim **'for all positive \(x\) and \(y\), \(\log_{10}(x + y) \leq \log_{10} x + \log_{10} y\)'**?

  1. A\(x = 10\), \(y = 100\)
  2. B\(x = y = 2\)
  3. C\(x = 5\), \(y = 5\)
  4. D\(x = 4\), \(y = 4\)
  5. E\(x = y = 1\)
Worked solution

\(x = y = 1\): \(\log 2 > 0 = \log 1 + \log 1\), so the inequality fails. For the others \(x + y \leq xy\) and the claim holds (\(\log\) is increasing).

12Graphs of functions · spec MM8.6 · Paper 2 style · ★★☆

The cubic \(y = x^3 + ax + b\) has three distinct real roots. Which of the following statements must be true?

  1. I\(a < 0\)
  2. II\(b \neq 0\)
  3. IIIThe curve has two turning points.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Three distinct real roots require two turning points (III), which needs \(y' = 3x^2 + a\) to have two roots, so \(a < 0\) (I). II is false: \(x^3 - x\) has roots \(0, \pm1\) and \(b = 0\).

13Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

A rectangle has integer side lengths and its area (in cm\(^2\)) is numerically equal to its perimeter (in cm). How many such rectangles are there (counting \(a \times b\) and \(b \times a\) once)?

  1. A\(4\)
  2. B\(3\)
  3. C\(0\)
  4. D\(1\)
  5. E\(2\)
  6. Finfinitely many
Worked solution

\(ab = 2a + 2b \Rightarrow (a - 2)(b - 2) = 4\): \((a - 2, b - 2) = (1, 4)\) or \((2, 2)\), giving \(3 \times 6\) and \(4 \times 4\).

14Trigonometric functions and equations · spec MM4.4 · Paper 2 style · ★★☆

Which of the following statements about the graph of \(y = \cos x\) is/are true?

  1. IIt is symmetric about the \(y\)-axis.
  2. IIIt is a translation of the graph of \(y = \sin x\) by \(\dfrac{\pi}{2}\) in the negative \(x\)-direction.
  3. IIIIt has period \(\pi\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(\cos(-x) = \cos x\) so I is true. \(\sin\left(x + \frac\pi2\right) = \cos x\), so II is true. The period of \(\cos\) is \(2\pi\), so III is false.

15Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

A sequence of \(10\) integers is such that the sum of any three consecutive terms is positive and the sum of any five consecutive terms is negative. Which of the following statements must be true?

  1. IThe sum of all \(10\) terms is negative.
  2. IIThe sequence contains at least one negative term.
  3. IIIThe sequence contains at least one positive term.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Terms \(1\)-\(5\) and \(6\)-\(10\) are two blocks of five, each with negative sum (I). A five-block has negative sum, so some term is negative (II). A three-block has positive sum, so some term is positive (III).

Which of the following statements is/are true about real numbers?

  2. IIFor all \(x\) there exists \(y\) such that \(x < y\) and \(x^2 < y^2\).

17Quadratic functions · spec MM1.3 · Paper 2 style · ★★☆

The quadratic equation \(ax^2 + bx + c = 0\) (with \(a \neq 0\)) has real coefficients. Which of the following statements is/are always true?

  1. IIf \(ac < 0\), the equation has two distinct real roots.
  2. IIIf \(b = 0\), the equation has no real roots.
  3. IIIIf the equation has a repeated root, then \(b^2 = 4ac\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: \(b^2 - 4ac > 0\) whenever \(ac < 0\), so true. II: \(x^2 - 4 = 0\) has \(b = 0\) and real roots, so false. III: a repeated root means the discriminant is zero, so true.

18Mathematical proof · spec Prf1 · Paper 1 style · ★★☆

Consider the claim: **if \(x\) and \(y\) are real numbers with \(x + y > 10\), then \(x > 5\) or \(y > 5\).** Which of the following proves it?

  1. ASuppose \(x \leq 5\) and \(y \leq 5\). Then \(x + y \leq 10\), contradicting \(x + y > 10\).
  2. BSuppose \(x > 5\). Then \(y > 10 - x\), so \(y > 5\).
  3. CIf \(x + y > 10\) then the average of \(x\) and \(y\) is more than \(5\), so both exceed \(5\).
  4. DTake \(x = 6\), \(y = 6\): then \(x + y = 12 > 10\) and \(x > 5\).
  5. EIf \(x > 5\) then the conclusion holds; if \(y > 5\) then the conclusion holds.
Worked solution

A is proof by contrapositive/contradiction. B assumes the conclusion, C is an example, D proves something false, E's conclusion ('both exceed \(5\)') is wrong.

19The logic of arguments · spec Arg1 · Paper 1 style · ★★☆

Which of the following statements is/are logically equivalent to 'if it is raining, then the ground is wet'?

  1. IIt is not raining, or the ground is wet.
  2. IIIf the ground is not wet, then it is not raining.
  3. IIIIf the ground is wet, then it is raining.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

'\(A \Rightarrow B\)' is equivalent to 'not \(A\), or \(B\)' (I) and to its contrapositive (II). III is the converse, which is not equivalent.

20Trigonometric functions and equations · spec MM4.5 · Paper 2 style · ★★☆

Which of the following is/are true for all real \(x\)?

  1. I\(\sin^2 x + \cos^2 x = 1\)
  2. II\(\sin(2x) = 2\sin x\)
  3. III\(\sin(x + \pi) = -\sin x\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I is the Pythagorean identity. II is false (e.g. \(x = \frac\pi2\): \(0 \neq 2\)). III: translating \(\sin\) by half a period negates it, so III is true.
