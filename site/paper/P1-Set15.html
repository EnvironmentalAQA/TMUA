1Trigonometric functions and equations · spec MM4.5 · Paper 1 style · ★☆☆

Given that \(\sin\theta = \dfrac{3}{5}\) and \(\theta\) is obtuse, find \(\tan\theta\).

  1. A\(-\dfrac{3}{4}\)
  2. B\(\dfrac{4}{3}\)
  3. C\(-\dfrac{4}{3}\)
  4. D\(-\dfrac{3}{5}\)
  5. E\(\dfrac{3}{4}\)
  6. F\(-\dfrac{4}{5}\)
Worked solution

\(\cos\theta = -\frac45\) (negative in the second quadrant), so \(\tan\theta = \frac{3/5}{-4/5} = -\frac34\).

Answer A · Trigonometric functions and equations (MM4.5) · question TRG-06
2Number, units and estimation · spec M2.13 · Paper 1 style · ★☆☆

A length is given as \(4.6\) cm correct to \(1\) decimal place, and a width as \(3\) cm correct to the nearest cm. Find the upper bound of the area.

  1. A\(16.1\) cm\(^2\)
  2. B\(11.375\) cm\(^2\)
  3. C\(16.45\) cm\(^2\)
  4. D\(16.275\) cm\(^2\)
  5. E\(14.375\) cm\(^2\)
  6. F\(13.8\) cm\(^2\)
Worked solution

Upper bounds \(4.65\) and \(3.5\): \(4.65 \times 3.5 = 16.275\).

Answer D · Number, units and estimation (M2.13) · question NUM-04
3GCSE algebra · spec M4.4 · Paper 1 style · ★☆☆

Expand and simplify \((x + 2)(x - 1)(x + 3)\).

  1. A\(x^3 + 4x^2 + 7x - 6\)
  2. B\(x^3 + 2x^2 - 5x - 6\)
  3. C\(x^3 - 4x^2 + x + 6\)
  4. D\(x^3 + 4x^2 - x - 6\)
  5. E\(x^3 + 6x^2 + 11x + 6\)
  6. F\(x^3 + 4x^2 + x - 6\)
Worked solution

\((x^2 + x - 2)(x + 3) = x^3 + 3x^2 + x^2 + 3x - 2x - 6 = x^3 + 4x^2 + x - 6\).

Answer F · GCSE algebra (M4.4) · question ALG-11
4Polynomials, factor and remainder theorems · spec MM1.6 · Paper 1 style · ★☆☆

The polynomial \(x^3 + ax^2 + bx + c\) has roots \(2\), \(-1\) and \(3\). Find the value of \(a + b + c\).

  1. A\(5\)
  2. B\(-5\)
  3. C\(-3\)
  4. D\(3\)
  5. E\(-7\)
  6. F\(7\)
Worked solution

\(p(1) = 1 + a + b + c\), and \(p(1) = (1-2)(1+1)(1-3) = (-1)(2)(-2) = 4\). So \(a + b + c = 3\). (Directly: \((x-2)(x+1)(x-3) = x^3 - 4x^2 + x + 6\).)

Answer D · Polynomials, factor and remainder theorems (MM1.6) · question POL-15
5Triangles, radians and sectors · spec MM4.2 · Paper 1 style · ★☆☆

A sector of a circle of radius \(6\) cm has area \(15\pi\) cm\(^2\). Find the arc length of the sector.

  1. A\(\dfrac{5\pi}{6}\) cm
  2. B\(10\pi\) cm
  3. C\(5\pi\) cm
  4. D\(\dfrac{5\pi}{2}\) cm
  5. E\(3\pi\) cm
  6. F\(15\pi\) cm
Worked solution

\(\frac12 r^2\theta = 18\theta = 15\pi \Rightarrow \theta = \frac{5\pi}{6}\). Arc \(= r\theta = 6 \cdot \frac{5\pi}{6} = 5\pi\).

Answer C · Triangles, radians and sectors (MM4.2) · question TRI-03
6Exponentials and logarithms · spec MM5.3 · Paper 1 style · ★☆☆

Solve \(3^{2x} = 4\). Give \(x\) in terms of logarithms to base \(3\).

  1. A\(x = \log_3 4 - 2\)
  2. B\(x = \log_3 2\)
  3. C\(x = \dfrac{\log_3 4}{4}\)
  4. D\(x = \log_2 3\)
  5. E\(x = \dfrac{1}{2}\log_3 2\)
  6. F\(x = 2\log_3 2\)
Worked solution

\(2x = \log_3 4 = 2\log_3 2\), so \(x = \log_3 2\).

Answer B · Exponentials and logarithms (MM5.3) · question LOG-02
7Circles and circle theorems · spec MM3.2 · Paper 1 style · ★☆☆

The circle with centre \((2, -1)\) passes through \((5, 3)\). Find the equation of the tangent to the circle at \((5, 3)\).

  1. A\(4x - 3y = 11\)
  2. B\(3x + 4y = 27\)
  3. C\(x + y = 8\)
  4. D\(3x + 4y = 15\)
  5. E\(3x - 4y = 3\)
  6. F\(4x + 3y = 29\)
Worked solution

Radius direction \((3, 4)\) has gradient \(\frac43\), so the tangent has gradient \(-\frac34\): \(y - 3 = -\frac34(x - 5) \Rightarrow 4y - 12 = -3x + 15 \Rightarrow 3x + 4y = 27\).

Answer B · Circles and circle theorems (MM3.2) · question CIR-03
8Graphs of functions · spec MM8.1 · Paper 1 style · ★☆☆

Which of the following functions is undefined at exactly two real values of \(x\)?

  1. A\(f(x) = \dfrac{1}{(x - 2)^2}\)
  2. B\(f(x) = \dfrac{x}{x^2}\)
  3. C\(f(x) = \sqrt{x - 2}\)
  4. D\(f(x) = \dfrac{1}{x^2 + 4}\)
  5. E\(f(x) = \dfrac{1}{x^2 - 4}\)
Worked solution

\(x^2 - 4 = 0\) at \(x = \pm 2\): two values. \(x^2 + 4\) is never zero; \(\frac{x}{x^2}\) and \(\frac{1}{(x-2)^2}\) are undefined at one value; \(\sqrt{x - 2}\) is undefined for all \(x < 2\).

Answer E · Graphs of functions (MM8.1) · question GRA-12
9Pythagoras, mensuration and 3D · spec M5.7 · Paper 1 style · ★☆☆

A cuboid measures \(3\) cm by \(4\) cm by \(12\) cm. Find the length of its longest diagonal.

  2. B\(13\) cm
  3. C\(15\) cm
  4. D\(5\) cm
  5. E\(\sqrt{119}\) cm
  6. F\(12.5\) cm
Worked solution

\(\sqrt{9 + 16 + 144} = \sqrt{169} = 13\).

Answer B · Pythagoras, mensuration and 3D (M5.7) · question MEN-01

Convert \(135^\circ\) to radians.

  1. A\(\dfrac{4\pi}{3}\)
  2. B\(\dfrac{3\pi}{8}\)
  3. C\(\dfrac{3\pi}{4}\)

11Pythagoras, mensuration and 3D · spec M5.16 · Paper 1 style · ★☆☆

A running track consists of two straights of length \(100\) m and two semicircular ends of radius \(r\). The total length of the track is \(400\) m. Find \(r\).

  1. A\(100\pi\)
  2. B\(\dfrac{100}{\pi}\)
  3. C\(\dfrac{200}{\pi}\)
  4. D\(\dfrac{400}{\pi}\)
  5. E\(\dfrac{300}{\pi}\)
  6. F\(\dfrac{50}{\pi}\)
Worked solution

\(200 + 2\pi r = 400 \Rightarrow r = \frac{100}{\pi}\).

Answer B · Pythagoras, mensuration and 3D (M5.16) · question MEN-12
12Quadratic functions · spec MM1.3 · Paper 1 style · ★☆☆

How many real solutions does the equation \(x^4 - 5x^2 + 4 = 0\) have?

  1. A\(2\)
  2. B\(4\)
  3. C\(5\)
  4. D\(0\)
  5. E\(1\)
  6. F\(3\)
Worked solution

Let \(u = x^2\): \(u^2 - 5u + 4 = (u-1)(u-4) = 0\), so \(x^2 = 1\) or \(x^2 = 4\), giving \(x = \pm1, \pm2\): four solutions.

Answer B · Quadratic functions (MM1.3) · question QUA-07
13Straight lines · spec MM3.1 · Paper 1 style · ★★☆

The distance between the parallel lines \(3x + 4y = 5\) and \(3x + 4y = 20\) is

  1. A\(15\)
  2. B\(3\)
  3. C\(4\)
  4. D\(\dfrac{15}{7}\)
  5. E\(1\)
  6. F\(5\)
Worked solution

The lines are \(3x + 4y = c\); the perpendicular direction is \((3, 4)\) of length \(5\). Distance \(= \frac{|20 - 5|}{5} = 3\). (Alternatively, the point \((0, \frac54)\) on the first line is \(3\) from the second.)

Answer B · Straight lines (MM3.1) · question LIN-13
14Indices and surds · spec MM1.2 · Paper 1 style · ★★☆

Given that \((2 + \sqrt{3})^2 = a + b\sqrt{3}\) and \((2+\sqrt{3})^{-1} = c + d\sqrt{3}\), where \(a\), \(b\), \(c\), \(d\) are integers, find the value of \(a + b + c + d\).

  1. A\(14\)
  2. B\(4\)
  3. C\(6\)
  4. D\(10\)
  5. E\(12\)
  6. F\(8\)
Worked solution

\((2+\sqrt3)^2 = 7 + 4\sqrt3\), so \(a = 7\), \(b = 4\). \((2+\sqrt3)^{-1} = \dfrac{2-\sqrt3}{4-3} = 2 - \sqrt3\), so \(c = 2\), \(d = -1\). Sum \(= 7 + 4 + 2 - 1 = 12\).

Answer E · Indices and surds (MM1.2) · question IND-06
15Straight lines · spec MM3.1 · Paper 1 style · ★★☆

The vertices of a triangle are \(A(0, 0)\), \(B(6, 0)\) and \(C(2, 4)\). Find the equation of the line through \(C\) that bisects the area of the triangle.

  1. A\(y = x + 2\)
  2. B\(y = -2x + 8\)
  3. C\(x = 2\)
  4. D\(y = 2x\)
  5. E\(y = 4x - 4\)
  6. F\(y = -4x + 12\)
Worked solution

A line through a vertex bisects the area iff it passes through the midpoint of the opposite side, \((3, 0)\). Through \((2, 4)\) and \((3, 0)\): gradient \(-4\), \(y = -4x + 12\).

Answer F · Straight lines (MM3.1) · question LIN-11
16Indices and surds · spec MM1.2 · Paper 1 style · ★★☆

Given that \(x = \sqrt{7} + \sqrt{3}\) and \(y = \sqrt{7} - \sqrt{3}\), find \(x^2 + y^2 - xy\).

  1. A\(24\)
  2. B\(16\)
  3. C\(4\)
  4. D\(20\)
  5. E\(20 - 2\sqrt{21}\)
  6. F\(12\)
Worked solution

\(x^2 + y^2 = (10 + 2\sqrt{21}) + (10 - 2\sqrt{21}) = 20\) and \(xy = 7 - 3 = 4\). So \(20 - 4 = 16\).

Answer B · Indices and surds (MM1.2) · question IND-11
17Differentiation · spec MM6.3 · Paper 1 style · ★★☆

The volume of a cuboid with a square base of side \(x\) is \(V = 4x^2 - x^3\) for \(0 < x < 4\). Find the maximum volume.

  1. A\(16\)
  2. B\(\dfrac{64}{27}\)
  3. C\(8\)
  4. D\(\dfrac{32}{3}\)
  5. E\(\dfrac{256}{27}\)
  6. F\(\dfrac{128}{27}\)
Worked solution

\(V' = 8x - 3x^2 = x(8 - 3x) = 0 \Rightarrow x = \frac83\). \(V = \frac{64}{9}\cdot 4 - \frac{512}{27} = \frac{768 - 512}{27} = \frac{256}{27}\).

Answer E · Differentiation (MM6.3) · question DIF-15
18Sequences and series · spec MM2.3 · Paper 1 style · ★★☆

A ball is dropped from a height of \(10\) m. After each bounce it rises to \(\dfrac{3}{5}\) of its previous height. Find the total distance travelled by the ball before it comes to rest.

  1. A\(30\) m
  2. B\(20\) m
  3. C\(40\) m
  4. D\(25\) m
  5. E\(50\) m
  6. F\(35\) m
Worked solution

Down: \(10 + 6 + 3.6 + \ldots = \dfrac{10}{1 - 3/5} = 25\). Up: \(6 + 3.6 + \ldots = 15\). Total \(40\) m.

Answer C · Sequences and series (MM2.3) · question SEQ-17
19Binomial expansion · spec MM2.4 · Paper 1 style · ★★☆

Find the value of \((\sqrt{2} + 1)^4 + (\sqrt{2} - 1)^4\).

  1. A\(34\)
  2. B\(36\)
  3. C\(17\)
  4. D\(34 + 24\sqrt2\)
  5. E\(24\sqrt{2}\)
  6. F\(16\)
Worked solution

Odd powers of \(\sqrt2\) cancel: \(2\left[(\sqrt2)^4 + \binom42(\sqrt2)^2 + 1\right] = 2[4 + 12 + 1] = 34\).

Answer A · Binomial expansion (MM2.4) · question BIN-11
20Polynomials, factor and remainder theorems · spec MM1.6 · Paper 1 style · ★★☆

When \(p(x)\) is divided by \((x-1)\) the remainder is \(3\), and when divided by \((x+1)\) the remainder is \(-1\). Find the remainder when \(p(x)\) is divided by \((x^2 - 1)\).

  1. A\(2\)
  2. B\(2x + 1\)
  3. C\(-x + 2\)
  4. D\(2x - 1\)
  5. E\(x + 2\)
  6. F\(3x - 1\)
Worked solution

The remainder has degree \(< 2\): \(ax + b\) with \(a + b = 3\) and \(-a + b = -1\). So \(b = 1\), \(a = 2\): remainder \(2x + 1\).

Answer B · Polynomials, factor and remainder theorems (MM1.6) · question POL-06
