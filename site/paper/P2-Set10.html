1Functions and transformations · spec MM8.2 · Paper 1 style · ★☆☆

The graph of \(y = f(x)\) has a maximum point at \((3, 8)\). The graph of \(y = f(x - a) + b\) has its maximum at \((1, 2)\). Find \(a + b\).

  1. A\(8\)
  2. B\(-2\)
  3. C\(-4\)
  4. D\(-8\)
  5. E\(4\)
  6. F\(0\)
Worked solution

The maximum moves from \((3, 8)\) to \((3 + a, 8 + b) = (1, 2)\), so \(a = -2\), \(b = -6\) and \(a + b = -8\).

2Sequences and series · spec MM2.2 · Paper 1 style · ★☆☆

How many terms of the arithmetic series \(3 + 7 + 11 + \ldots\) are needed for the sum to first exceed \(500\)?

  1. A\(17\)
  2. B\(16\)
  3. C\(11\)
  4. D\(14\)
  5. E\(18\)
  6. F\(15\)
Worked solution

\(S_n = \frac n2(6 + 4(n-1)) = n(2n + 1)\). \(n = 15\): \(465\); \(n = 16\): \(528 > 500\). So \(16\).

3Polynomials, factor and remainder theorems · spec MM1.6 · Paper 1 style · ★☆☆

Find the coefficient of \(x^2\) in the expansion of \((x + 1)(x - 2)(2x + 3)\).

  1. A\(1\)
  2. B\(-3\)
  3. C\(-2\)
  4. D\(-1\)
  5. E\(2\)
  6. F\(3\)
Worked solution

\((x+1)(x-2) = x^2 - x - 2\); multiply by \((2x + 3)\): the \(x^2\) term is \(3x^2 - 2x^2 = x^2\), coefficient \(1\).

4The logic of arguments · spec Arg4 · Paper 1 style · ★☆☆

Which of the following is the negation of **'\(x > 3\) and \(y \leq 5\)'**?

  1. A\(x < 3\) and \(y > 5\)
  2. B\(x < 3\) or \(y \geq 5\)
  3. C\(x \leq 3\) or \(y \geq 5\)
  4. D\(x \leq 3\) and \(y > 5\)
  5. E\(x \leq 3\) or \(y > 5\)
Worked solution

Not (\(A\) and \(B\)) is (not \(A\)) or (not \(B\)). Not \(x > 3\) is \(x \leq 3\); not \(y \leq 5\) is \(y > 5\).

5Chains of reasoning · spec Prf5 · Paper 1 style · ★☆☆

The digits \(1\) to \(9\) are placed in a \(3 \times 3\) grid so that every row and every column has the same sum. What is that sum?

  1. A\(45\)
  2. B\(15\)
  3. C\(20\)
  4. D\(18\)
  5. E\(12\)
  6. F\(10\)
Worked solution

The three rows together contain every digit once, so \(3 \times\) (row sum) \(= 1 + 2 + \cdots + 9 = 45\), giving \(15\).

6Circles and circle theorems · spec MM3.2 · Paper 2 style · ★☆☆

The circle \(C\) has centre \((a, b)\) and radius \(r\). \(P\): '\(r > |b|\)'. \(Q\): '\(C\) crosses the \(x\)-axis at two distinct points'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

The distance from the centre to the \(x\)-axis is \(|b|\); the circle cuts the axis twice exactly when this is less than \(r\).

7Identifying errors in proofs · spec Err1 · Paper 1 style · ★☆☆

Claim: for all real \(x\), if \(x^2 > 9\) then \(x > 3\).

  1. ISuppose \(x^2 > 9\).
  2. IITaking square roots of both sides, \(x > 3\).
  3. IIIThis proves the claim.

Which of the following is true?

  1. AThe claim is false; the first error is on line II, since \(x = -4\) satisfies \(x^2 > 9\) but not \(x > 3\).
  2. BThe claim and proof are both correct.
  3. CThe claim is true but line II should say \(|x| > 3\) and then deduce \(x > 3\).
  4. DThe claim is false; the first error is on line I.
  5. EThe claim is true; the first error is on line III.
Worked solution

\(x^2 > 9\) gives \(|x| > 3\), i.e. \(x > 3\) or \(x < -3\). The claim itself is false, and line II is where the invalid deduction happens.

8The logic of arguments · spec Arg1 · Paper 1 style · ★☆☆

Consider the statement: **if \(n\) is a multiple of \(6\), then \(n\) is a multiple of \(3\).** Which of the following is its contrapositive?

  1. AIf \(n\) is not a multiple of \(3\), then \(n\) is not a multiple of \(6\).
  2. BIf \(n\) is a multiple of \(3\), then \(n\) is a multiple of \(6\).
  3. CIf \(n\) is not a multiple of \(6\), then \(n\) is not a multiple of \(3\).
  4. D\(n\) is a multiple of \(6\) if and only if \(n\) is a multiple of \(3\).
  5. EIf \(n\) is a multiple of \(3\), then \(n\) is not a multiple of \(6\).
Worked solution

The contrapositive of 'if \(A\) then \(B\)' is 'if not \(B\) then not \(A\)'. It is logically equivalent to the original; B is the converse and C is the inverse.

9The logic of arguments · spec Arg1 · Paper 1 style · ★☆☆

For a positive integer \(n\), consider the statement: **if \(n\) is prime, then \(n\) is odd.** Which one of the following is true?

  1. AThe statement is true and its converse is true.
  2. BThe statement is true and its converse is false.
  3. CThe statement is false and its converse is true.
  4. DThe statement is false and its converse is false.
Worked solution

11Trigonometric functions and equations · spec MM4.6 · Paper 2 style · ★☆☆

Consider the equation \(\sin x = k\) where \(k\) is a real constant. Which of the following statements is/are true?

  1. IFor every \(k\) with \(-1 < k < 1\) the equation has exactly two solutions in \(0 \leq x < 2\pi\).
  2. IIFor \(k = 1\) the equation has exactly one solution in \(0 \leq x < 2\pi\).
  3. IIIFor every real \(k\) the equation has at least one solution.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

12Sequences and series · spec MM2.3 · Paper 2 style · ★☆☆

Which of the following geometric series is/are convergent?

  1. I\(1 + 0.9 + 0.81 + \ldots\)
  2. II\(3 - 3 + 3 - 3 + \ldots\)
  3. III\(100 + 10 + 1 + 0.1 + \ldots\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

A geometric series converges if and only if \(|r| < 1\). I has \(r = 0.9\), III has \(r = 0.1\): both converge. II has \(r = -1\) and does not converge.

13Mathematical proof · spec Prf2 · Paper 1 style · ★★☆

For a positive integer \(n\) it is known that: (i) if \(n\) is a multiple of \(4\) then \(n\) is not a multiple of \(6\); (ii) \(n\) is a multiple of \(12\) or \(n\) is a multiple of \(4\). What can be deduced?

  1. AThe premises are inconsistent unless \(n\) is a multiple of \(4\) but not of \(6\); in particular \(n\) cannot be a multiple of \(12\).
  2. B\(n\) is not a multiple of \(4\).
  3. C\(n\) is a multiple of \(12\).
  4. D\(n\) is a multiple of \(6\).
  5. ENothing can be deduced.
Worked solution

If \(n\) were a multiple of \(12\) it would be a multiple of both \(4\) and \(6\), contradicting (i). So by (ii) \(n\) is a multiple of \(4\), and by (i) not a multiple of \(6\).

14GCSE algebra · spec M4.19 · Paper 2 style · ★★☆

The \(n\)th term of a sequence is \(\dfrac{n^2 + 1}{2n}\). Which of the following statements is/are true?

  1. IThe \(5\)th term is \(2.6\).
  2. IIEvery term after the first is greater than the previous term.
  3. IIISome term of the sequence equals \(10\).
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

I: \(\frac{26}{10} = 2.6\). II: \(u_n = \frac n2 + \frac{1}{2n}\); \(u_1 = 1\), \(u_2 = 1.25\), and for \(n \geq 1\) the increase \(\frac12 - \frac{1}{2n(n+1)} > 0\), so increasing. III: \(n^2 - 20n + 1 = 0\) has no integer solutions (discriminant \(396\) is not a square), so false.

Answer E · GCSE algebra (M4.19) · question ALG-08
15Functions and transformations · spec MM8.2 · Paper 2 style · ★★☆

Let \(f(x) = x^2\) for all real \(x\), and let \(g\) be the function whose graph is obtained by translating the graph of \(y = f(x)\) by \(2\) units in the positive \(x\)-direction and then reflecting in the \(y\)-axis. Which of the following statements is/are true?

  1. I\(g(x) = (x + 2)^2\)
  2. II\(g(x) = (x - 2)^2\)
  3. IIIThe graph of \(g\) has its vertex at \((-2, 0)\)
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

Translation gives \((x - 2)^2\); reflecting in the \(y\)-axis replaces \(x\) by \(-x\): \((-x - 2)^2 = (x + 2)^2\), with vertex at \((-2, 0)\).

16Chains of reasoning · spec Prf5 · Paper 1 style · ★★☆

Alice, Ben and Cara each make one statement. Alice: 'Ben is lying.' Ben: 'Cara is lying.' Cara: 'Alice and Ben are both lying.' Exactly one of them is telling the truth. Who is it?

  1. ABen
  2. BAlice
  3. CCara
  4. DIt cannot be determined.
  5. EThe situation is impossible.
Worked solution

If Alice is truthful then Ben lies, so Cara is truthful: two truth-tellers, impossible. If Cara is truthful then Alice and Ben both lie; but Alice lying means Ben is truthful: contradiction. So Ben is the truth-teller: Cara lies (indeed Ben is not lying) and Alice lies (Ben is not lying), which is consistent.

Answer A · Chains of reasoning (Prf5) · question RSN-17
17Identifying errors in proofs · spec Err2 · Paper 1 style · ★★☆

A student writes the following argument.

  1. I\(0.1 > 0.01\).
  2. IITaking logarithms to base \(10\) of both sides: \(-1 > -2\).
  3. IIIMultiplying both sides by \(\log_{10}\frac12\), which is negative, reverses the inequality: \(-\log_{10}\frac12 < -2\log_{10}\frac12\).

Which of the following is correct?

  1. AAll three lines are correct.
  2. BLine II is wrong: taking logarithms reverses an inequality.
  3. CLine III is wrong: \(\log_{10}\frac12\) is positive.
  4. DLine II is wrong: \(\log_{10} 0.1 = 1\).
  5. ELine I is wrong.
Worked solution

Logarithms are increasing functions, so line II is valid; \(\log_{10}\frac12 < 0\), so reversing the inequality in line III is correct.

18Mathematical proof · spec Prf2 · Paper 1 style · ★★☆

Every element of a set \(S\) of integers is either a multiple of \(3\) or a multiple of \(5\). Every multiple of \(3\) in \(S\) is negative. \(S\) contains the number \(10\). Which of the following statements must be true?

  1. I\(S\) contains a positive multiple of \(5\).
  2. II\(S\) contains no positive multiple of \(3\).
  3. III\(S\) contains a negative number.
  1. Anone of them
  2. BI only
  3. CII only
  4. DIII only
  5. EI and II only
  6. FI and III only
  7. GII and III only
  8. HI, II and III
Worked solution

\(10 \in S\) is a positive multiple of \(5\) (I). Multiples of \(3\) in \(S\) are negative, so none is positive (II). III fails: \(S = \{10\}\) satisfies everything.

19Differentiation · spec MM6.3 · Paper 2 style · ★★☆

Let \(f\) be a polynomial. \(P\): '\(f'(x) > 0\) for all real \(x\)'. \(Q\): '\(f(x) = 0\) has exactly one real root'. Which one of the following is true?

  1. AP is necessary and sufficient for Q.
  2. BP is necessary but not sufficient for Q.
  3. CP is sufficient but not necessary for Q.
  4. DP is neither necessary nor sufficient for Q.
Worked solution

If \(f' > 0\) everywhere, \(f\) is strictly increasing and (being an odd-degree polynomial) crosses the axis exactly once: \(P\) is sufficient. But \(f(x) = x^3\) has exactly one root and \(f'(0) = 0\), so \(P\) is not necessary.

Answer C · Differentiation (MM6.3) · question X2-02
20Indices and surds · spec MM1.1 · Paper 2 style · ★★★

For how many integer values of \(n\) with \(1 \leq n \leq 100\) is \(\sqrt{n} + \sqrt{n+1}\) rational?

  1. A\(9\)
  2. B\(1\)
  3. C\(10\)
  4. D\(0\)
  5. E\(2\)
  6. F\(100\)
Worked solution

For the sum to be rational, both \(\sqrt n\) and \(\sqrt{n+1}\) would need to be rational (if one is irrational, \(\sqrt n + \sqrt{n+1}\) squared gives \(2n + 1 + 2\sqrt{n(n+1)}\) and \(n(n+1)\) is never a perfect square for \(n \geq 1\) since \(n^2 < n(n+1) < (n+1)^2\)). No two consecutive positive integers are both squares, so the answer is \(0\).
